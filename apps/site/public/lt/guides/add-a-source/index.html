Pridėk šaltinį (Stremio plėtinys)

Laststream priima Stremio plėtinius (priedus): įklijuok jų manifesto adresą, ir jų nuorodos atsiras, kai paleisi pavadinimą.

  • 3 min
  • Windows
  • Android
  • Naršyklė

Prieš pradedant

  • Prisijungusi paskyra, pagrindinis profilis.
  • Plėtinio manifesto adresas (dažniausiai baigiasi /manifest.json).

Žingsniai

Kiekvienoje ekrano nuotraukoje geltonas rėmelis rodo, kur bakstelti ar spustelėti; skaičiai nurodo eilės tvarką. Programa veikia prancūzų kalba: ekrano nuotraukose rodomas jos anglų vertimas.

  1. Bakstelk savo avatarą, tada „Nustatymai“.

  2. Kairiajame stulpelyje pasirink „Šaltiniai“ (1), tada „Pridėti Stremio priedą“ (2).

  3. Įklijuok adresą į „Aukštesnio lygio priedo URL“. Nuorodos stremio:// priimamos, o /manifest.json pridedamas, jei trūksta.

    Ekrano nuotraukose adresas prasideda http://localhost: tai žemiau pateikto pavyzdinio plėtinio adresas, paleistas vietoje vadovui. Įklijuoji tą adresą, kurį pateikia plėtinys, kurį nori įdiegti.

  4. Manifestas nuskaitomas iš karto: pasirodo priedo pavadinimas, logotipas ir būsena (1). Nustatymų apačioje bakstelk „Išsaugoti“ (2).

  5. Atidaryk filmą ir bakstelk „Groti“: priedo nuorodos pasirodys panelėje „Šaltiniai“.

Verta žinoti

  • Kortelės „…“ meniu: redaguoti, atidaryti konfigūraciją, nukopijuoti URL, įjungti arba išjungti, pašalinti.
  • Tvarka svarbi: šaltinis 1 užklausiamas pirmas. Keisk ją rankenėle ⋮⋮ arba rodyklėmis ↑ ↓.
  • Norėdamas pašalinti: pašalink, tada „Išsaugoti“.
  • Debrid raktas Laststream nevedamas: kiekvienas priedas tvarko debrid savo konfigūracijoje.

Pavyzdys: paprastas plėtinys

Plėtinys – tai nedidelė žiniatinklio paslauga, turinti du adresus: /manifest.json ir /stream/{type}/{id}.json.

Manifestas:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Atsakymas į /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Tai tiksliai plėtinys, naudotas šio vadovo ekrano nuotraukoms.

Vadovai

Laststream nėra susijusi su Stremio.

Šis produktas naudoja TMDB API, bet jo nerekomenduoja ir nesertifikuoja TMDB.

Ekrano nuotraukos padarytos su demonstraciniu katalogu: išgalvoti pavadinimai ir DI sukurti plakatai.
