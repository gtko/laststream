Dodaj vir (razširitev Stremio)

Laststream sprejema razširitve Stremio (dodatke): prilepi naslov njihovega manifesta in njihove povezave se pokažejo, ko predvajaš naslov.

  • 3 min
  • Windows
  • Android
  • Brskalnik

Preden začneš

  • Prijavljen račun, na glavnem profilu.
  • Naslov manifesta razširitve (običajno se konča z /manifest.json).

Koraki

Na vsakem posnetku zaslona rumeni okvir kaže, kje tapniti ali klikniti; številke določajo vrstni red. Aplikacija je v francoščini: posnetki prikazujejo njen angleški prevod.

  1. Tapni svoj avatar, nato „Nastavitve“.

  2. V levem stolpcu izberi „Viri“ (1), nato „Dodaj dodatek Stremio“ (2).

  3. Prilepi naslov v „URL izvornega dodatka“. Povezave stremio:// so sprejete, /manifest.json pa se doda, če manjka.

    Na posnetkih se naslov začne z http://localhost: to je primer razširitve spodaj, zagnan lokalno za vodnik. Prilepiš naslov, ki ga poda razširitev, ki jo želiš namestiti.

  4. Manifest se takoj prebere: ime dodatka, logotip in stanje se prikažejo (1). Tapni „Shrani“ na dnu Nastavitev (2).

  5. Odpri film in tapni „Predvajaj“: povezave dodatka se prikažejo v panelu „Viri“.

Dobro je vedeti

  • Meni „…“ na kartici: uredi, odpri konfiguracijo, kopiraj URL, omogoči ali onemogoči, odstrani.
  • Vrstni red je pomemben: vir 1 se preveri prvi. Spremeni ga z ročajem ⋮⋮ ali s puščicama ↑ ↓.
  • Za odstranitev: odstrani, nato „Shrani“.
  • Ključ Debrid ni vnesen v Laststream: vsak dodatek obravnava Debrid v svoji konfiguraciji.

Primer: osnovna razširitev

Razširitev je majhna spletna storitev, ki ponuja dva naslova: /manifest.json in /stream/{type}/{id}.json.

Manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Odgovor /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

To je natančno razširitev, uporabljeno za posnetke zaslona tega vodnika.
