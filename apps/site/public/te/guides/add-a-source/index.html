మూలాన్ని జోడించు (Stremio ఎక్స్‌టెన్షన్)

Laststream Stremio ఎక్స్‌టెన్షన్‌లను (addons) అంగీకరిస్తుంది: వాటి manifest చిరునామాను అతికించు, మీరు ఒక శీర్షికను ప్లే చేసినప్పుడు వాటి లింక్‌లు కనిపిస్తాయి.

  • 3 నిమిషాలు
  • Windows
  • Android
  • బ్రౌజర్

ప్రారంభించే ముందు

  • ప్రధాన ప్రొఫైల్‌లో సైన్ ఇన్ చేసిన ఖాతా.
  • ఎక్స్‌టెన్షన్ manifest చిరునామా (ఇది సాధారణంగా /manifest.jsonతో ముగుస్తుంది).

దశలు

ప్రతి స్క్రీన్‌షాట్‌లో, పసుపు ఫ్రేమ్ ఎక్కడ నొక్కాలో లేదా క్లిక్ చేయాలో చూపుతుంది; సంఖ్యలు క్రమాన్ని ఇస్తాయి. యాప్ ఫ్రెంచ్‌లో ఉంది: స్క్రీన్‌షాట్‌లు దాని ఆంగ్ల అనువాదాన్ని చూపుతాయి.

  1. మీ అవతార్‌ను నొక్కు, ఆపై “సెట్టింగ్‌లు”.

  2. ఎడమ కాలమ్‌లో, “మూలాలు” (1) ఎంచుకో, ఆపై “Stremio addonను జోడించు” (2).

  3. చిరునామాను “Upstream addon URL”లో అతికించు. stremio:// లింక్‌లు అంగీకరించబడతాయి, మరియు లేకపోతే /manifest.json జోడించబడుతుంది.

    స్క్రీన్‌షాట్‌లలో చిరునామా http://localhostతో మొదలవుతుంది: ఇది గైడ్ కోసం స్థానికంగా నడిచే దిగువ ఉదాహరణ ఎక్స్‌టెన్షన్. మీరు ఇన్‌స్టాల్ చేయాలనుకునే ఎక్స్‌టెన్షన్ ఇచ్చిన చిరునామాను అతికిస్తారు.

  4. manifest వెంటనే చదవబడుతుంది: addon పేరు, లోగో మరియు స్థితి కనిపిస్తాయి (1). సెట్టింగ్‌ల దిగువన ఉన్న “సేవ్” నొక్కు (2).

  5. ఒక సినిమాను తెరిచి “ప్లే” నొక్కు: addon లింక్‌లు “మూలాలు” ప్యానెల్‌లో కనిపిస్తాయి.

తెలుసుకోవలసినవి

  • కార్డ్‌లోని “…” మెనూ: సవరించు, కాన్ఫిగరేషన్ తెరువు, URLను కాపీ చేయి, ప్రారంభించు లేదా నిలిపివేయి, తీసివేయి.
  • క్రమం ముఖ్యం: మూలం 1 ముందుగా ప్రశ్నించబడుతుంది. ⋮⋮ హ్యాండిల్ లేదా ↑ ↓ బాణాలతో మార్చు.
  • అన్‌ఇన్‌స్టాల్ చేయడానికి: తీసివేయి, ఆపై “సేవ్”.
  • debrid కీ Laststreamలో నమోదు చేయబడదు: ప్రతి addon దాని స్వంత కాన్ఫిగరేషన్‌లో debridను నిర్వహిస్తుంది.

ఉదాహరణ: ఒక ప్రాథమిక ఎక్స్‌టెన్షన్

ఎక్స్‌టెన్షన్ అంటే రెండు చిరునామాలను బహిర్గతం చేసే ఒక చిన్న వెబ్ సేవ: /manifest.json మరియు /stream/{type}/{id}.json.

manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json ప్రతిస్పందన:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

ఈ గైడ్ స్క్రీన్‌షాట్‌ల కోసం ఉపయోగించిన ఎక్స్‌టెన్షన్ ఇదే.

మునుపటి గైడ్ పిల్లల ప్రొఫైల్‌ను సృష్టించు తదుపరి గైడ్ లైవ్ టీవీని సెటప్ చేయి (M3U ప్లేలిస్ట్)
Laststream

Laststream ఎలాంటి కంటెంట్‌ను హోస్ట్ చేయదు: మీరు కాన్ఫిగర్ చేసే ఎక్స్‌టెన్షన్‌లను అది చదువుతుంది. ఆహ్వానం ద్వారా మాత్రమే.

గైడ్‌లు

Laststream, Stremioతో అనుబంధం లేనిది.

ఈ ఉత్పత్తి TMDB APIని ఉపయోగిస్తుంది, కానీ TMDB ఆమోదించలేదు లేదా ధృవీకరించలేదు.

డెమో కేటలాగ్‌తో చేసిన స్క్రీన్‌షాట్‌లు: కల్పిత శీర్షికలు మరియు AI-సృష్టించిన పోస్టర్‌లు.
