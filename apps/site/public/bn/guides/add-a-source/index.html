একটি উৎস যোগ করো (Stremio এক্সটেনশন)

Laststream Stremio এক্সটেনশন (অ্যাডঅন) গ্রহণ করে: তাদের manifest ঠিকানা পেস্ট করো, এবং শিরোনাম চালালে তাদের লিংক দেখা যায়।

  • ৩ মিনিট
  • Windows
  • Android
  • ব্রাউজার

শুরু করার আগে

  • সাইন-ইন করা অ্যাকাউন্ট, মূল প্রোফাইলে।
  • এক্সটেনশনের manifest-এর ঠিকানা (সাধারণত /manifest.json দিয়ে শেষ হয়)।

ধাপসমূহ

প্রতিটি স্ক্রিনশটে হলুদ ফ্রেম দেখায় কোথায় চাপতে বা ক্লিক করতে হবে; নম্বর ক্রম দেয়। অ্যাপটি ফরাসি ভাষায়: স্ক্রিনশটে এর ইংরেজি অনুবাদ দেখানো হয়েছে।

  1. তোমার অবতারে চাপো, তারপর “সেটিংস”।

  2. বাঁদিকের কলামে “উৎস” (১) বেছে নাও, তারপর “একটি Stremio অ্যাড-অন যোগ করো” (২)।

  3. ঠিকানাটি “Upstream অ্যাড-অন URL”-এ পেস্ট করো। stremio:// লিংক গ্রহণযোগ্য, এবং না থাকলে /manifest.json যোগ হয়।

    স্ক্রিনশটে ঠিকানাটি http://localhost দিয়ে শুরু: এটি নিচের উদাহরণ এক্সটেনশন, গাইডের জন্য স্থানীয়ভাবে চালানো। যে এক্সটেনশন ইনস্টল করতে চাও তার দেওয়া ঠিকানাটি পেস্ট করো।

  4. manifest সঙ্গে সঙ্গে পড়া হয়: অ্যাডঅনের নাম, লোগো ও অবস্থা দেখায় (১)। সেটিংসের নিচে “সংরক্ষণ করো” (২)-এ চাপো।

  5. একটি সিনেমা খুলে “প্লে”-তে চাপো: অ্যাডঅনের লিংক “উৎস” প্যানেলে দেখা যাবে।

জানা ভালো

  • কার্ডের “…” মেনু: সম্পাদনা, কনফিগারেশন খোলা, URL কপি, চালু বা বন্ধ, সরানো।
  • ক্রম গুরুত্বপূর্ণ: উৎস ১ আগে জিজ্ঞাসা করা হয়। ⋮⋮ হ্যান্ডেল বা ↑ ↓ তীর দিয়ে বদলাও।
  • আনইনস্টল করতে: সরাও, তারপর “সংরক্ষণ করো”।
  • Debrid কী Laststream-এ লেখা হয় না: প্রতিটি অ্যাড-অন তার নিজের কনফিগারেশনে Debrid পরিচালনা করে।

উদাহরণ: একটি সাধারণ এক্সটেনশন

একটি এক্সটেনশন হলো একটি ছোট ওয়েব সেবা যা দুটি ঠিকানা প্রকাশ করে: /manifest.json ও /stream/{type}/{id}.json।

manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json-এর প্রতিক্রিয়া:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

এই গাইডের স্ক্রিনশটে ঠিক এই এক্সটেনশনটি ব্যবহার করা হয়েছে।
