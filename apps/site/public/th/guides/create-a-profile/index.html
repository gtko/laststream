สร้างโปรไฟล์

ทุกคนในบ้านมีโปรไฟล์ของตัวเอง คลัง ความคืบหน้า และการตั้งค่าตามไปทุกอุปกรณ์

  • 2 นาที
  • Windows
  • Android
  • เบราว์เซอร์

ก่อนเริ่ม

  • บัญชีที่ลงชื่อเข้าใช้แล้ว
  • เฉพาะโปรไฟล์หลัก (หรือคนที่รู้รหัส) เท่านั้นที่เพิ่มโปรไฟล์ได้

ขั้นตอน

ในภาพหน้าจอแต่ละภาพ กรอบสีเหลืองแสดงตำแหน่งที่ต้องแตะหรือคลิก ตัวเลขบอกลำดับ แอปแสดงผลเป็นภาษาฝรั่งเศส ภาพหน้าจอแสดงคำแปลภาษาอังกฤษ

  1. แตะอวาตาร์มุมขวาบน (1) แล้ว “สลับโปรไฟล์” (2)

  2. ที่หน้าจอ “ใครกำลังดู?” แตะไทล์ “เพิ่มโปรไฟล์”

  3. ใน “โปรไฟล์ใหม่” พิมพ์ชื่อ (1 ไม่เกิน 20 ตัวอักษร) หากต้องการ เลือกอวาตาร์ด้วย “เปลี่ยนอวาตาร์” (2) แล้วเลือกสีจากแปดสี (3)

  4. ไม่บังคับ: “รหัส PIN ของโปรไฟล์” 4 หลัก (1) ซึ่งจะถูกถามทุกครั้งที่เปิดโปรไฟล์นี้

    แตะ “สร้างโปรไฟล์” มุมขวาบน (2)

  5. โปรไฟล์ใหม่ปรากฏถัดจากโปรไฟล์อื่น แตะ “เสร็จสิ้น” เพื่อกลับไป “ใครกำลังดู?” แล้วแตะโปรไฟล์เพื่อเปิด

ควรรู้

  • แก้ไขโปรไฟล์: “จัดการโปรไฟล์” แล้วแตะโปรไฟล์ เปลี่ยนชื่อ อวาตาร์ สี หรือรหัส PIN ได้
  • ลบโปรไฟล์: ทางเดิม แล้วไปที่โซนอันตรายด้านล่าง (พิมพ์ชื่อเพื่อยืนยัน) ลบโปรไฟล์หลักไม่ได้
  • สำหรับเด็ก ให้ทำตามคู่มือ สร้างโปรไฟล์เด็ก แทน
