ตั้งค่าทีวีสด (เพลย์ลิสต์ M3U)

ทีวีสดอ่านเพลย์ลิสต์ M3U จากผู้ให้บริการหรือบริการ IPTV และผังรายการ XMLTV ที่ไม่บังคับ

  • 5 นาที
  • Windows
  • Android

ก่อนเริ่ม

  • แอป Windows หรือ Android: เบราว์เซอร์ไม่สามารถเข้าถึงเพลย์ลิสต์ส่วนใหญ่ได้
  • ที่อยู่เพลย์ลิสต์ M3U (และที่อยู่คู่มือ XMLTV หากมี)

ขั้นตอน

ในภาพหน้าจอแต่ละภาพ กรอบสีเหลืองแสดงตำแหน่งที่ต้องแตะหรือคลิก ตัวเลขบอกลำดับ แอปแสดงผลเป็นภาษาฝรั่งเศส ภาพหน้าจอแสดงคำแปลภาษาอังกฤษ

  1. แตะอวาตาร์ แล้วเลือก “การตั้งค่า” จากนั้น “ทีวีสด” ในคอลัมน์ซ้าย

  2. ใน “เพิ่มเพลย์ลิสต์ M3U” กรอกชื่อ (1 ไม่บังคับ) “ที่อยู่เพลย์ลิสต์” (2) และหากมี “คู่มือรายการ (XMLTV)” (3, .xml หรือ .xml.gz)

    แตะ “เพิ่มเพลย์ลิสต์” (4) หรือ “นำเข้าไฟล์” (.m3u) จากอุปกรณ์ได้

  3. เมื่อข้อความ “เพิ่มช่อง … แล้ว อัปเดตผังรายการแล้ว” ปรากฏ ให้กลับหน้าหลักแล้วเปิดแท็บ “สด”

  4. ช่องจะปรากฏพร้อมป้าย “กล่องสื่อ” และรายการ คอลัมน์ซ้ายกรองตามหมวด

  5. แตะรายการเพื่อดูรายละเอียด แล้วแตะ “ดู”

ควรรู้

  • สมาชิก Freebox: “ตรวจหา Freebox” เพิ่มช่องของกล่องได้โดยไม่ต้องพิมพ์อะไร
  • แต่ละเพลย์ลิสต์ปิดใช้งาน รีเฟรช หรือลบจากแถวของตนได้ ภายใต้ “เพลย์ลิสต์ M3U”
  • เพลย์ลิสต์ของบัญชีจัดการโดยโปรไฟล์หลัก

รูปแบบที่คาดหวัง

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

บรรทัดแรกต้องเป็น #EXTM3U แต่ละ #EXTINF ตามด้วยที่อยู่สตรีม (http, https, rtsp, rtp หรือ udp) group-title คือหมวด tvg-chno คือหมายเลข (1 ถึง 9999) tvg-id เชื่อมกับผังรายการ XMLTV

ขีดจำกัดค่า
ขนาดเพลย์ลิสต์20 MB
หมดเวลาโหลด20 s
รีเฟรชอัตโนมัติทุก 24 ชั่วโมง
เพลย์ลิสต์ต่อบัญชี20
ผังรายการตั้งแต่ตอนนี้ถึง +24 ชั่วโมง

หากใช้ไม่ได้

  • “ที่อยู่นี้ไม่ส่งเพลย์ลิสต์ M3U กลับมา” → ที่อยู่ชี้ไปยังหน้าเว็บหรือไฟล์ในรูปแบบอื่น
  • “ไม่พบช่องในเพลย์ลิสต์นี้” → ไฟล์ว่างหรือรูปแบบผิด
  • “ไม่สามารถเข้าถึงที่อยู่” → ตรวจสอบที่อยู่และการเชื่อมต่อ (และเครือข่ายของกล่องสื่อสำหรับ Freebox)
  • ในเบราว์เซอร์ → เว็บเบราว์เซอร์ไม่สามารถเข้าถึงเพลย์ลิสต์ส่วนใหญ่ได้: ใช้แอป Windows หรือ Android
