키즈 프로필 만들기

키즈 프로필에는 연령 등급이 확인되고 선택한 연령 이하인 작품만 나와요. 나가려면 부모 코드가 필요해요.

  • 3분
  • Windows
  • Android
  • 브라우저

단계

각 스크린샷에서 노란 테두리는 탭하거나 클릭할 위치를, 숫자는 순서를 보여 줘요. 앱은 프랑스어로 되어 있으며, 스크린샷에는 영어 번역이 표시돼요.

  1. 프로필 만들기 가이드처럼 (아바타, “프로필 전환”, “프로필 추가”) “새 프로필”을 연 다음 이름을 입력하세요.

  2. “부모 보호 기능”에서 “키즈 프로필”을 켜세요.

  3. “최대 연령”(1)을 고르세요: 10, 12, 16 또는 18 (기본값은 12). “허용된 섹션”(2)에서 아래 표를 보고 체크하세요.

  4. 메인 프로필에 아직 부모 코드가 없다면 4자리 숫자를 입력하세요(1). 키즈 프로필을 나갈 때 보호해 줘요.

    “프로필 만들기”(2)를 누르세요.

  5. “완료”를 누른 다음 키즈 프로필을 선택하세요. 홈에는 해당 연령에 맞는 작품만 나와요.

허용된 섹션

섹션기본으로 체크됨
만화예
가족 영화예
키즈 시리즈예
디즈니와 픽사의 명작예
키즈용 애니메이션예
키즈를 위한 신작예
플랫폼(Disney+, Netflix)예
키즈 TV아니요

“키즈 TV”가 꺼져 있으면 아이에게는 TV 탭이 숨겨져요.

키즈 프로필 나가기

아바타를 탭한 다음 “프로필 전환”을 누르세요. 부모 코드를 물어봐요.

알아두면 좋은 점

  • 연령 등급이 없는 작품은 숨겨져요.
  • 자녀에게는 설정, 통계, 친구, 라이브러리 공유가 보이지 않아요.

Laststream은 콘텐츠를 호스팅하지 않아요. 설정한 애드온을 읽을 뿐이에요. 초대로만 이용할 수 있어요.
