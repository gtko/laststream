소스 추가하기 (Stremio 애드온)

Laststream은 Stremio 애드온(addons)을 지원해요. 매니페스트 주소를 붙여넣으면 작품을 재생할 때 그 링크가 나타나요.

  • 3분
  • Windows
  • Android
  • 브라우저

시작하기 전에

  • 로그인한 계정, 메인 프로필 사용.
  • 애드온 매니페스트의 주소(보통 /manifest.json으로 끝나요).

단계

각 스크린샷에서 노란 테두리는 탭하거나 클릭할 위치를, 숫자는 순서를 보여 줘요. 앱은 프랑스어로 되어 있으며, 스크린샷에는 영어 번역이 표시돼요.

  1. 아바타를 누른 다음 “설정”을 선택하세요.

  2. 왼쪽 열에서 “소스”(1)를 고른 다음 “Stremio 애드온 추가”(2)를 선택하세요.

  3. 주소를 “상위 애드온 URL”에 붙여넣으세요. stremio:// 링크도 받아들이며, 없으면 /manifest.json이 자동으로 추가돼요.

    스크린샷의 주소는 http://localhost로 시작해요. 이는 이 가이드를 위해 로컬에서 실행한 아래 예시 애드온이에요. 설치하려는 애드온이 제공한 주소를 붙여넣으세요.

  4. 매니페스트는 바로 읽혀요. 애드온의 이름, 로고, 상태가 나타나요(1). 설정 하단의 “저장”(2)을 누르세요.

  5. 영화를 열고 “재생”을 누르면 애드온의 링크가 “소스” 패널에 나타나요.

알아두면 좋은 점

  • 카드의 “…” 메뉴: 편집, 설정 열기, URL 복사, 사용 또는 사용 안 함, 삭제.
  • 순서가 중요해요. 소스 1이 먼저 조회돼요. ⋮⋮ 핸들 또는 ↑ ↓ 화살표로 순서를 바꿀 수 있어요.
  • 제거하려면 삭제한 다음 “저장”을 누르세요.
  • 디브리드 키는 Laststream에 입력하지 않아요. 각 애드온이 자신의 설정에서 디브리드를 처리해요.

예시: 기본 애드온

애드온은 두 개의 주소, 즉 /manifest.json과 /stream/{type}/{id}.json을 제공하는 작은 웹 서비스예요.

매니페스트:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json의 응답:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

이 가이드의 스크린샷에 사용된 바로 그 애드온이에요.

Laststream은 콘텐츠를 호스팅하지 않아요. 설정한 애드온을 읽을 뿐이에요. 초대로만 이용할 수 있어요.

가이드

Laststream은 Stremio와 제휴 관계가 아니에요.

이 제품은 TMDB API를 사용하지만 TMDB의 보증이나 인증을 받지 않았어요.
