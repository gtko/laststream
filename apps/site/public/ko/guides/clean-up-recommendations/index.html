추천 정리하기

특정 작품이나 장르에 관심이 없나요? 홈에서 제거하세요. 검색과 해당 작품 페이지에서는 여전히 찾을 수 있어요.

  • 2분
  • Windows
  • Android
  • 브라우저

단계

각 스크린샷에서 노란 테두리는 탭하거나 클릭할 위치를, 숫자는 순서를 보여 줘요. 앱은 프랑스어로 되어 있으며, 스크린샷에는 영어 번역이 표시돼요.

  1. 홈에서 포스터의 “…”(또는 마우스 오른쪽 클릭, 길게 누르기)을 누른 다음 “다시 추천하지 않기”를 선택하세요.

  2. 작품 페이지에서는 재생 버튼 옆의 “…” 버튼을 누르세요.

  3. …그다음 “홈에서 추천하지 않기”.

  4. “설정”의 “홈” 카테고리: “숨긴 작품”(1)은 제거한 작품 수를 보여 주고, “관리”에서 다시 되돌릴 수 있어요.

    “추천하지 않을 장르”에서 장르(2)를 누르면 그 장르의 모든 작품이 홈에서 사라져요. “모두 초기화”를 누르면 전부 다시 나타나요.

알아두면 좋은 점

  • 영화를 끝까지 보거나 90%까지 재생한 경우, 그리고 시리즈를 끝까지 본 경우에는 홈에서 더 이상 추천하지 않아요. 라이브러리, 검색, 해당 작품 페이지에는 그대로 남아 있어요.
  • 이 설정은 열려 있는 프로필에만 적용돼요.
