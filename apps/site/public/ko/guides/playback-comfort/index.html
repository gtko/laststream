재생 편의 설정

즉시 시작, 연결 상태에 맞는 화질, 건너뛴 인트로, 연속 에피소드. 재생을 더 편하게 만드는 설정들이에요.

  • 2분
  • Windows
  • Android
  • 브라우저

단계

각 스크린샷에서 노란 테두리는 탭하거나 클릭할 위치를, 숫자는 순서를 보여 줘요. 앱은 프랑스어로 되어 있으며, 스크린샷에는 영어 번역이 표시돼요.

  1. “설정”의 “재생” 카테고리(1)를 여세요. “최고 소스 시작”(2)을 켜면 소스 목록을 거치지 않고 바로 재생이 시작돼요.

  2. “최대 해상도”(1)는 데이터를 아끼기 위해 자동으로 고르는 화질을 제한해요. “내 연결 속도”(2)는 연결에 비해 너무 무거운 소스를 제외해요. “자동(측정)”을 유지하거나 속도를 고르세요.

  3. 시리즈의 경우: “인트로 건너뛰기”(1)는 오프닝 크레딧이 감지되면 건너뛰고, “다음 에피소드 자동 재생”(2)은 엔딩 크레딧 후 다음 편을 시작해요. “이전 줄거리 건너뛰기”는 “지난 이야기”를 건너뛰어요.

  4. 느린 소스에서 재생이 끊긴다면 “버퍼 크기”를 “크게” 또는 “최대”로 올리세요.

알아두면 좋은 점

  • 최대 해상도 때문에 다른 소스를 직접 고르지 못하는 일은 없어요.
  • “내 연결 테스트”를 누르면 바로 속도를 측정해요.
  • Android에서는 큰 버퍼 때문에 재생 시작과 탐색이 약간 느려질 수 있어요(최대에서는 최대 30초). 다음 재생부터 적용돼요.
  • 애니메이션: “필러 에피소드 건너뛰기”를 켜면 연속 재생 시 필러 에피소드를 건너뛰어요.
