프로필 만들기

집안 모든 사람이 각자의 프로필을 가져요. 라이브러리, 진행 상황, 설정이 모든 기기에서 따라다녀요.

  • 2분
  • Windows
  • Android
  • 브라우저

시작하기 전에

  • 로그인한 계정.
  • 메인 프로필(또는 그 코드를 아는 사람)만 프로필을 추가할 수 있어요.

단계

각 스크린샷에서 노란 테두리는 탭하거나 클릭할 위치를, 숫자는 순서를 보여 줘요. 앱은 프랑스어로 되어 있으며, 스크린샷에는 영어 번역이 표시돼요.

  1. 오른쪽 위의 아바타(1)를 누른 다음 “프로필 전환”(2)을 선택하세요.

  2. “누가 시청하나요?” 화면에서 “프로필 추가” 타일을 누르세요.

  3. “새 프로필”에서 이름(1, 최대 20자)을 입력하세요. 원하면 “아바타 변경”(2)으로 아바타를 고르고, 8가지 색상 견본 중 하나(3)를 선택하세요.

  4. 선택 사항: 4자리 “프로필 PIN 코드”(1)를 설정하면 이후 이 프로필을 열 때 입력하라고 요청해요.

    오른쪽 위의 “프로필 만들기”(2)를 누르세요.

  5. 새 프로필이 다른 프로필 옆에 나타나요. “완료”를 눌러 “누가 시청하나요?”로 돌아간 다음 프로필을 누르면 열려요.

알아두면 좋은 점

  • 프로필을 편집하려면 “프로필 관리”에서 프로필을 누르세요. 이름, 아바타, 색상, PIN 코드를 바꿀 수 있어요.
  • 프로필을 삭제하려면 같은 경로로 가서 맨 아래 위험 영역에서 이름을 입력해 확인하세요. 메인 프로필은 삭제할 수 없어요.
  • 자녀를 위해서라면 키즈 프로필 만들기 가이드를 따라 하세요.

Laststream은 콘텐츠를 호스팅하지 않아요. 설정한 애드온을 읽을 뿐이에요. 초대로만 이용할 수 있어요.

가이드

Laststream은 Stremio와 제휴 관계가 아니에요.

이 제품은 TMDB API를 사용하지만 TMDB의 보증이나 인증을 받지 않았어요.
