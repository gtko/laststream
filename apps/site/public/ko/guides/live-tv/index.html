실시간 TV 설정하기 (M3U 재생 목록)

실시간 TV는 공급자나 IPTV 서비스의 M3U 재생 목록과, 선택 사항인 XMLTV 편성표를 읽어요.

  • 5분
  • Windows
  • Android

시작하기 전에

  • Windows 또는 Android 앱을 사용하세요. 브라우저로는 대부분의 재생 목록에 접근할 수 없어요.
  • M3U 재생 목록 주소(있다면 XMLTV 편성표 주소도).

단계

각 스크린샷에서 노란 테두리는 탭하거나 클릭할 위치를, 숫자는 순서를 보여 줘요. 앱은 프랑스어로 되어 있으며, 스크린샷에는 영어 번역이 표시돼요.

  1. 아바타를 누른 다음 “설정”을 고르고, 왼쪽 열의 “실시간 TV”를 선택하세요.

  2. “M3U 재생 목록 추가”에서 이름(1, 선택 사항), “재생 목록 주소”(2), 그리고 있다면 “편성표(XMLTV)”(3, .xml 또는 .xml.gz)를 입력하세요.

    “재생 목록 추가”(4)를 누르세요. 기기에서 .m3u 파일을 “파일 가져오기”로 추가할 수도 있어요.

  3. “… 채널 추가됨, 편성표 업데이트됨” 메시지가 나타나면 홈으로 돌아가 “실시간” 탭을 여세요.

  4. 채널은 “Box” 배지와 함께 편성 정보가 표시돼요. 왼쪽 열에서 카테고리별로 필터링할 수 있어요.

  5. 프로그램을 탭해 세부 정보를 확인한 다음 “시청하기”를 누르세요.

알아두면 좋은 점

  • Freebox 가입자라면 “내 Freebox 감지”를 눌러 아무것도 입력하지 않고 박스의 채널을 추가할 수 있어요.
  • 각 재생 목록은 “M3U 재생 목록” 아래에서 줄마다 사용 안 함, 새로고침, 삭제할 수 있어요.
  • 계정의 재생 목록은 메인 프로필에서 관리해요.

예상 형식

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

첫 줄은 반드시 #EXTM3U여야 해요. 각 #EXTINF 뒤에는 스트림 주소(http, https, rtsp, rtp 또는 udp)가 와요. group-title은 카테고리, tvg-chno는 번호(1~9999), tvg-id는 XMLTV 편성표와 연결돼요.

제한값
재생 목록 크기20MB
로딩 제한 시간20 s
자동 새로고침24시간마다
계정당 재생 목록 수20
편성표지금부터 +24시간까지

작동하지 않는 경우

  • “이 주소는 M3U 재생 목록을 반환하지 않아요.” → 주소가 웹 페이지나 다른 형식의 파일을 가리키고 있어요.
  • “이 재생 목록에서 채널을 찾을 수 없어요.” → 파일이 비어 있거나 형식이 잘못됐어요.
  • “주소에 연결할 수 없음” → 주소와 인터넷 연결을 확인하세요(Freebox라면 박스의 네트워크도 확인하세요).
  • 브라우저에서 → 웹 브라우저로는 대부분의 재생 목록에 접근할 수 없어요. Windows 또는 Android 앱을 사용하세요.

앱은 이 메시지를 프랑스어로 표시해요.
