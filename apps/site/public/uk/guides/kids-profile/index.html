Створення дитячого профілю

Дитячий профіль показує лише назви з відомим віковим рейтингом, не вищим за обраний вік. Щоб вийти, потрібен батьківський код.

  • 3 хв
  • Windows
  • Android
  • Браузер

Кроки

На кожному скриншоті жовта рамка показує, де натиснути, а цифри — порядок дій. Застосунок працює французькою; на скриншотах показано його англійський переклад.

  1. Відкрий «Новий профіль», як у посібнику Створення профілю (аватар, «Змінити профіль», «Додати профіль»), потім введи його ім’я.

  2. У розділі «Батьківський контроль» увімкни «Дитячий профіль».

  3. Обери «Максимальний вік» (1): 10, 12, 16 або 18 (за замовчуванням 12). Познач «Дозволені розділи» (2), див. таблицю нижче.

  4. Якщо в головному профілі ще немає батьківського коду, введи 4-значний (1). Він захищає вихід із дитячого профілю.

    Натисни «Створити профіль» (2).

  5. Натисни «Готово», потім дитячий профіль: його головна показує лише назви для його віку.

Вихід із дитячого профілю

Натисни його аватар, потім «Змінити профіль»: запитається батьківський код.

Корисно знати

  • Назва без вікового рейтингу прихована.
  • Дитина не бачить налаштувань, статистики, друзів чи спільного доступу до бібліотеки.
