Додавання джерела (доповнення Stremio)

Laststream підтримує доповнення Stremio: встав адресу їхнього маніфесту, і їхні посилання з’являться, коли ти відтворюватимеш назву.

  • 3 хв
  • Windows
  • Android
  • Браузер

Перш ніж почати

  • Обліковий запис із входом, на головному профілі.
  • Адреса маніфесту доповнення (зазвичай закінчується на /manifest.json).

Кроки

На кожному скриншоті жовта рамка показує, де натиснути, а цифри — порядок дій. Застосунок працює французькою; на скриншотах показано його англійський переклад.

  1. Натисни свій аватар, потім «Налаштування».

  2. У лівій колонці обери «Джерела» (1), потім «Додати доповнення Stremio» (2).

  3. Встав адресу в «URL вихідного доповнення». Посилання stremio:// приймаються, а /manifest.json додається, якщо його немає.

    На скриншотах адреса починається з http://localhost: це приклад доповнення нижче, запущений локально для посібника. Ти вставляєш адресу, яку дає доповнення, що хочеш встановити.

  4. Маніфест зчитується одразу: з’являються назва доповнення, логотип і статус (1). Натисни «Зберегти» внизу налаштувань (2).

  5. Відкрий фільм і натисни «Відтворити»: посилання доповнення з’являться на панелі «Джерела».

Корисно знати

  • Меню «…» на картці: змінити, відкрити конфігурацію, скопіювати URL, увімкнути або вимкнути, видалити.
  • Порядок важливий: джерело 1 опитується першим. Зміни його за допомогою ручки ⋮⋮ або стрілок ↑ ↓.
  • Щоб видалити: вилучи, потім «Зберегти».
  • Ключ debrid не вводиться в Laststream: кожне доповнення обробляє debrid у своїй конфігурації.

Приклад: просте доповнення

Доповнення — це невеликий веб-сервіс, що відкриває дві адреси: /manifest.json і /stream/{type}/{id}.json.

Маніфест:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Відповідь /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Це саме те доповнення, яке використано для скриншотів цього посібника.

Посібники

Laststream не пов’язаний зі Stremio.

Цей продукт використовує API TMDB, але не схвалений і не сертифікований TMDB.

Скриншоти зроблено з демонстраційним каталогом: вигадані назви та постери, створені ШІ.
