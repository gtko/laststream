Adaugă o sursă (extensie Stremio)

Laststream acceptă extensiile Stremio (addons): lipește adresa manifestului lor și linkurile lor apar când redai un titlu.

  • 3 min
  • Windows
  • Android
  • Browser

Înainte de a începe

  • Un cont conectat, pe profilul principal.
  • Adresa manifestului extensiei (de obicei se termină cu /manifest.json).

Pași

Pe fiecare captură de ecran, cadrul galben arată unde să atingi sau să faci clic; numerele dau ordinea. Aplicația este în franceză, iar capturile arată traducerea ei în engleză.

  1. Atinge avatarul tău, apoi „Setări”.

  2. În coloana din stânga, alege „Surse” (1), apoi „Adaugă o extensie Stremio” (2).

  3. Lipește adresa în „URL extensie în amonte”. Linkurile stremio:// sunt acceptate, iar /manifest.json este adăugat dacă lipsește.

    Pe capturi, adresa începe cu http://localhost: este extensia de exemplu de mai jos, rulată local pentru ghid. Lipești adresa oferită de extensia pe care vrei să o instalezi.

  4. Manifestul este citit imediat: numele, logo-ul și starea extensiei apar (1). Apasă „Salvează” din partea de jos a Setărilor (2).

  5. Deschide un film și apasă „Redă”: linkurile extensiei apar în panoul „Surse”.

De știut

  • Meniul „…” al unui card: editează, deschide configurarea, copiază URL-ul, activează sau dezactivează, elimină.
  • Ordinea contează: sursa 1 este interogată prima. Schimb-o cu mânerul ⋮⋮ sau cu săgețile ↑ ↓.
  • Pentru a dezinstala: elimină, apoi „Salvează”.
  • Cheia debrid nu se introduce în Laststream: fiecare extensie gestionează debrid în propria configurare.

Exemplu: o extensie de bază

O extensie este un mic serviciu web care expune două adrese: /manifest.json și /stream/{type}/{id}.json.

Manifestul:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Răspunsul pentru /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Este exact extensia folosită pentru capturile acestui ghid.
