တိုက်ရိုက် TV ပြင်ဆင်ခြင်း (M3U playlist)

တိုက်ရိုက် TV သည် ဝန်ဆောင်မှုပေးသူ သို့မဟုတ် IPTV ဝန်ဆောင်မှုမှ M3U playlist များကို ဖတ်သည်၊ ရွေးချယ်စရာအနေဖြင့် XMLTV အစီအစဉ်လမ်းညွှန်ကိုလည်း ဖတ်နိုင်သည်။

  • 5 မိနစ်
  • Windows
  • Android

မစတင်မီ

  • Windows သို့မဟုတ် Android အက်ပ် — ဘရောင်ဇာသည် playlist အများစုကို မရောက်နိုင်ပါ။
  • M3U playlist လိပ်စာ (နှင့် ရှိလျှင် XMLTV လမ်းညွှန် လိပ်စာ)။

အဆင့်များ

screenshot တစ်ခုစီတွင် အဝါရောင်ဘောင်က နှိပ်ရမည့်နေရာကို ပြသည်၊ နံပါတ်များက အစဉ်အတိုင်း ပြသည်။ အက်ပ်သည် ပြင်သစ်ဖြင့် ဖြစ်သည်၊ screenshot များက အင်္ဂလိပ်ဘာသာပြန်ကို ပြသည်။

  1. avatar ကို နှိပ်ပြီး “ဆက်တင်များ”၊ ထို့နောက် ဘယ်ဘက်ကော်လံရှိ “တိုက်ရိုက် TV”။

  2. “M3U playlist ထည့်ရန်” တွင် အမည် (1၊ ရွေးချယ်နိုင်)၊ “Playlist လိပ်စာ” (2) ကို ဖြည့်ပါ၊ ရှိလျှင် “အစီအစဉ်လမ်းညွှန် (XMLTV)” (3၊ .xml သို့မဟုတ် .xml.gz) ကိုပါ ဖြည့်ပါ။

    “Playlist ထည့်ရန်” (4) ကို နှိပ်ပါ။ စက်မှ “ဖိုင် သွင်းရန်” (.m3u) ကိုလည်း ရွေးနိုင်သည်။

  3. “… ချန်နယ် ထည့်ပြီး၊ လမ်းညွှန် အပ်ဒိတ်လုပ်ပြီး” စာတိုပေါ်လာသည်နှင့် ပင်မသို့ ပြန်သွားပြီး “Live” tab ကို ဖွင့်ပါ။

  4. ချန်နယ်များသည် အစီအစဉ်များနှင့်အတူ “Box” အမှတ်တံဆိပ်ဖြင့် ပေါ်သည်။ ဘယ်ဘက်ကော်လံက အမျိုးအစားအလိုက် စစ်ထုတ်သည်။

  5. အစီအစဉ်တစ်ခုကို နှိပ်ပြီး အသေးစိတ် ကြည့်ပါ၊ ထို့နောက် “ကြည့်ရန်”။

သိထားသင့်သည်များ

  • Freebox သုံးသူ — “Freebox ကို ရှာဖွေ” က box ၏ ချန်နယ်များကို ဘာမျှ ရိုက်ထည့်စရာမလိုဘဲ ထည့်ပေးသည်။
  • playlist တစ်ခုစီကို “M3U playlists” အောက်ရှိ အတန်းမှ ပိတ်နိုင်၊ ပြန်လတ်ဆတ်စေနိုင်၊ ဖယ်ရှားနိုင်သည်။
  • အကောင့်၏ playlist များကို ပင်မပရိုဖိုင်က စီမံသည်။

မျှော်လင့်ထားသော ပုံစံ

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

ပထမစာကြောင်းသည် #EXTM3U ဖြစ်ရမည်။ #EXTINF တစ်ခုစီနောက်တွင် stream လိပ်စာ (http၊ https၊ rtsp၊ rtp သို့မဟုတ် udp) လိုက်သည်။ group-title က အမျိုးအစားကို ပေးသည်၊ tvg-chno က နံပါတ် (1 မှ 9999) ကို ပေးသည်၊ tvg-id က XMLTV လမ်းညွှန်နှင့် ချိတ်သည်။

ကန့်သတ်ချက်တန်ဖိုး
Playlist အရွယ်အစား20 MB
တင်ရာတွင် အချိန်ကုန်ခြင်း20 s
အလိုအလျောက် ပြန်လတ်ဆတ်စေခြင်း24 နာရီတိုင်း
အကောင့်တစ်ခုလျှင် playlist များ20
အစီအစဉ်လမ်းညွှန်ယခုမှ +24 နာရီအထိ

အလုပ်မလုပ်ပါက

  • “ဤလိပ်စာက M3U playlist ပြန်မပေးပါ။” → လိပ်စာသည် ဝဘ်စာမျက်နှာ သို့မဟုတ် အခြားပုံစံဖိုင်ကို ညွှန်ပြနေသည်။
  • “ဤ playlist တွင် ချန်နယ် မတွေ့ပါ။” → ဖိုင်အလွတ် သို့မဟုတ် ပုံစံမှားနေသည်။
  • “လိပ်စာ မရောက်နိုင်ပါ” → လိပ်စာနှင့် ချိတ်ဆက်မှုကို စစ်ပါ (Freebox အတွက် box ၏ network ကိုပါ)။
  • ဘရောင်ဇာတွင် → ဝဘ်ဘရောင်ဇာသည် playlist အများစုကို မရောက်နိုင်ပါ၊ Windows သို့မဟုတ် Android အက်ပ်ကို သုံးပါ။

အက်ပ်သည် ဤစာများကို ပြင်သစ်ဖြင့် ပြသည်။
