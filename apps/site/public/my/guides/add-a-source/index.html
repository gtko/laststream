ရင်းမြစ် ထည့်ခြင်း (Stremio extension)

Laststream သည် Stremio extension များ (addons) ကို လက်ခံသည် — manifest လိပ်စာကို ကူးထည့်လိုက်လျှင် ခေါင်းစဉ်ဖွင့်သည့်အခါ ၎င်းတို့၏ လင့်ခ်များ ပေါ်လာမည်။

  • 3 မိနစ်
  • Windows
  • Android
  • ဘရောင်ဇာ

မစတင်မီ

  • လက်မှတ်ထိုးဝင်ထားသော အကောင့်၊ ပင်မပရိုဖိုင်တွင်။
  • extension ၏ manifest လိပ်စာ (များသောအားဖြင့် /manifest.json ဖြင့် အဆုံးသတ်သည်)။

အဆင့်များ

screenshot တစ်ခုစီတွင် အဝါရောင်ဘောင်က နှိပ်ရမည့်နေရာကို ပြသည်၊ နံပါတ်များက အစဉ်အတိုင်း ပြသည်။ အက်ပ်သည် ပြင်သစ်ဖြင့် ဖြစ်သည်၊ screenshot များက အင်္ဂလိပ်ဘာသာပြန်ကို ပြသည်။

  1. avatar ကို နှိပ်ပြီး “ဆက်တင်များ”။

  2. ဘယ်ဘက်ကော်လံတွင် “ရင်းမြစ်များ” (1) ကို ရွေး၊ ထို့နောက် “Stremio addon ထည့်ရန်” (2)။

  3. လိပ်စာကို “Upstream addon URL” တွင် ကူးထည့်ပါ။ stremio:// လင့်ခ်များကို လက်ခံသည်၊ /manifest.json မပါလျှင် အလိုအလျောက် ထည့်သည်။

    screenshot များတွင် လိပ်စာသည် http://localhost ဖြင့် စသည်၊ ၎င်းသည် အောက်ပါ နမူနာ extension ဖြစ်ပြီး လမ်းညွှန်အတွက် ဒေသတွင်း run ထားသည်။ တပ်ဆင်လိုသော extension ပေးသော လိပ်စာကို ကူးထည့်ပါ။

  4. manifest ကို ချက်ချင်း ဖတ်သည် — addon ၏အမည်၊ လိုဂိုနှင့် အခြေအနေ ပေါ်လာသည် (1)။ ဆက်တင်များ၏ အောက်ခြေရှိ “သိမ်းရန်” (2) ကို နှိပ်ပါ။

  5. ရုပ်ရှင်တစ်ခုဖွင့်ပြီး “Play” ကို နှိပ်ပါ — addon ၏ လင့်ခ်များသည် “ရင်းမြစ်များ” panel တွင် ပေါ်လာမည်။

သိထားသင့်သည်များ

  • ကတ်တစ်ခု၏ “…” မီနူး — ပြင်ဆင်ရန်၊ configuration ဖွင့်ရန်၊ URL ကူးရန်၊ ဖွင့်/ပိတ်ရန်၊ ဖယ်ရှားရန်။
  • အစဉ်အရေးကြီးသည် — ရင်းမြစ် 1 ကို ဦးစွာ စစ်သည်။ ⋮⋮ လက်ကိုင် သို့မဟုတ် ↑ ↓ မြှားဖြင့် ပြောင်းပါ။
  • ဖယ်ရှားရန် — ဖျက်ပြီး “သိမ်းရန်”။
  • debrid key ကို Laststream တွင် ထည့်ခြင်းမရှိပါ — addon တစ်ခုစီက ၎င်း၏ ကိုယ်ပိုင် configuration တွင် debrid ကို ကိုင်တွယ်သည်။

ဥပမာ — အခြေခံ extension

Extension ဆိုသည်မှာ လိပ်စာနှစ်ခု ပေးသော သေးငယ်သည့် ဝဘ်ဝန်ဆောင်မှုတစ်ခု ဖြစ်သည် — /manifest.json နှင့် /stream/{type}/{id}.json။

manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json ၏ တုံ့ပြန်ချက်:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

ဤလမ်းညွှန်၏ screenshot များတွင် သုံးထားသော extension ဖြစ်သည်။

ယခင်လမ်းညွှန် ကလေးပရိုဖိုင် ဖန်တီးခြင်း နောက်လမ်းညွှန် တိုက်ရိုက် TV ပြင်ဆင်ခြင်း (M3U playlist)
Laststream

Laststream သည် အကြောင်းအရာ မဖော်ဆောင်ပါ — သင်သတ်မှတ်သော extension များကို ဖတ်သည်။ ဖိတ်ကြားမှုဖြင့်သာ။

လမ်းညွှန်များ

Laststream သည် Stremio နှင့် မပတ်သက်ပါ။

ဤထုတ်ကုန်သည် TMDB API ကို သုံးသော်လည်း TMDB မှ အတည်ပြု သို့မဟုတ် လက်မှတ်ရခြင်း မရှိပါ။

ဒီမိုကက်တလော့ဂ်ဖြင့် ပြုလုပ်ထားသော screenshot များ — ဖန်တီးထားသော ခေါင်းစဉ်များနှင့် AI ဖန်တီးထားသော ပိုစတာများ။
