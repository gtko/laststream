Siapkan TV langsung (playlist M3U)

TV langsung membaca playlist M3U dari penyedia atau layanan IPTV-mu, dan opsional panduan program XMLTV.

  • 5 mnt
  • Windows
  • Android

Sebelum kamu mulai

  • Aplikasi Windows atau Android: browser tidak bisa menjangkau sebagian besar playlist.
  • Alamat playlist M3U-mu (dan, jika punya, alamat panduan XMLTV).

Langkah

Pada setiap tangkapan layar, bingkai kuning menunjukkan di mana harus mengetuk atau mengklik; angkanya menunjukkan urutannya. Aplikasinya berbahasa Prancis: tangkapan layar menampilkan terjemahan Inggrisnya.

  1. Ketuk avatarmu, lalu «Pengaturan», lalu «TV langsung» di kolom kiri.

  2. Di «Tambahkan playlist M3U», isi nama (1, opsional), «Alamat playlist» (2) dan, jika ada, «Panduan program (XMLTV)» (3, .xml atau .xml.gz).

    Ketuk «Tambahkan playlist» (4). Kamu juga bisa «Impor berkas» (.m3u) dari perangkat.

  3. Setelah pesan «… saluran ditambahkan, panduan diperbarui» muncul, kembali ke beranda dan buka tab «Live».

  4. Saluranmu muncul dengan lencana «Box», beserta programnya. Kolom kiri memfilter menurut kategori.

  5. Ketuk sebuah program untuk melihat detailnya, lalu «Tonton».

Perlu diketahui

  • Pelanggan Freebox: «Deteksi Freebox-ku» menambahkan saluran box tanpa perlu mengetik apa pun.
  • Setiap playlist bisa dinonaktifkan, disegarkan, atau dihapus dari barisnya, di bawah «Playlist M3U».
  • Playlist akun dikelola oleh profil utama.

Format yang diharapkan

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

Baris pertama harus #EXTM3U. Setiap #EXTINF diikuti alamat stream (http, https, rtsp, rtp, atau udp). group-title menentukan kategori, tvg-chno nomornya (1 sampai 9999), tvg-id menghubungkan ke panduan XMLTV.

Jika tidak berhasil

  • «Alamat ini tidak mengembalikan playlist M3U.» → alamat mengarah ke halaman web atau berkas dengan format lain.
  • «Tidak ada saluran ditemukan di playlist ini.» → berkas kosong atau rusak.
  • «Alamat tidak dapat dijangkau» → periksa alamatnya dan koneksimu (serta jaringan box-mu untuk Freebox).
  • Di browser → browser web tidak bisa menjangkau sebagian besar playlist: gunakan aplikasi Windows atau Android.
