Tambahkan sumber (ekstensi Stremio)

Laststream menerima ekstensi Stremio (add-on): tempel alamat manifest-nya dan tautannya muncul saat kamu memutar judul.

  • 3 mnt
  • Windows
  • Android
  • Browser

Sebelum kamu mulai

  • Akun yang sudah masuk, di profil utama.
  • Alamat manifest ekstensi (biasanya diakhiri dengan /manifest.json).

Langkah

Pada setiap tangkapan layar, bingkai kuning menunjukkan di mana harus mengetuk atau mengklik; angkanya menunjukkan urutannya. Aplikasinya berbahasa Prancis: tangkapan layar menampilkan terjemahan Inggrisnya.

  1. Ketuk avatarmu, lalu «Pengaturan».

  2. Di kolom kiri, pilih «Sumber» (1), lalu «Tambahkan add-on Stremio» (2).

  3. Tempel alamatnya ke «URL add-on upstream». Tautan stremio:// diterima, dan /manifest.json ditambahkan jika belum ada.

    Pada tangkapan layar, alamatnya diawali dengan http://localhost: itu adalah ekstensi contoh di bawah, dijalankan secara lokal untuk panduan ini. Kamu menempelkan alamat yang diberikan oleh ekstensi yang ingin kamu pasang.

  4. Manifest langsung dibaca: nama, logo, dan status add-on muncul (1). Ketuk «Simpan» di bagian bawah Pengaturan (2).

  5. Buka sebuah film dan ketuk «Putar»: tautan dari add-on muncul di panel «Sumber».

Perlu diketahui

  • Menu «…» pada kartu: ubah, buka konfigurasi, salin URL, aktifkan atau nonaktifkan, hapus.
  • Urutan penting: sumber 1 dicek lebih dulu. Ubah dengan pegangan ⋮⋮ atau panah ↑ ↓.
  • Untuk mencopot pemasangan: hapus, lalu «Simpan».
  • Kunci debrid tidak dimasukkan di Laststream: setiap add-on mengurus debrid dalam konfigurasinya sendiri.

Contoh: ekstensi dasar

Ekstensi adalah layanan web kecil yang menyediakan dua alamat: /manifest.json dan /stream/{type}/{id}.json.

Manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Respons dari /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Ini adalah ekstensi yang persis dipakai untuk tangkapan layar panduan ini.
