மூலத்தைச் சேர் (Stremio துணை நிரல்)

Laststream Stremio துணை நிரல்களை (addons) ஏற்கும்: அவற்றின் manifest முகவரியை ஒட்டு, ஒரு தலைப்பை இயக்கும்போது அவற்றின் இணைப்புகள் தோன்றும்.

  • 3 நிமிடங்கள்
  • Windows
  • Android
  • உலாவி

தொடங்குவதற்கு முன்

  • உள்நுழைந்த கணக்கு, முதன்மை சுயவிவரத்தில்.
  • துணை நிரலின் manifest முகவரி (பொதுவாக /manifest.json இல் முடியும்).

படிகள்

ஒவ்வொரு திரைப்பிடிப்பிலும், மஞ்சள் சட்டம் எங்கு தட்ட அல்லது கிளிக் செய்ய வேண்டும் என்பதைக் காட்டுகிறது; எண்கள் வரிசையைத் தருகின்றன. செயலி பிரெஞ்சு மொழியில் உள்ளது: திரைப்பிடிப்புகள் அதன் ஆங்கில மொழிபெயர்ப்பைக் காட்டுகின்றன.

  1. உங்கள் அவதாரைத் தட்டு, பிறகு “அமைப்புகள்”.

  2. இடது பக்க நெடுவரிசையில், “மூலங்கள்” (1) ஐத் தேர்ந்தெடு, பிறகு “Stremio துணை நிரலைச் சேர்” (2).

  3. முகவரியை “மேல்நிலை துணை நிரல் URL” இல் ஒட்டு. stremio:// இணைப்புகள் ஏற்கப்படும், விடுபட்டால் /manifest.json சேர்க்கப்படும்.

    திரைப்பிடிப்புகளில் முகவரி http://localhost உடன் தொடங்குகிறது: அது கீழே உள்ள எடுத்துக்காட்டு துணை நிரல், வழிகாட்டிக்காக உள்ளூரில் இயங்குகிறது. நீங்கள் நிறுவ விரும்பும் துணை நிரல் வழங்கும் முகவரியை ஒட்டுகிறீர்கள்.

  4. மேனிஃபெஸ்ட் உடனே படிக்கப்படும்: துணை நிரலின் பெயர், லோகோ மற்றும் நிலை தோன்றும் (1). அமைப்புகளின் அடியில் “சேமி” என்பதைத் தட்டு (2).

  5. ஒரு திரைப்படத்தைத் திறந்து “இயக்கு” என்பதைத் தட்டு: துணை நிரலின் இணைப்புகள் “மூலங்கள்” பலகத்தில் தோன்றும்.

தெரிந்துகொள்ள வேண்டியவை

  • அட்டையின் “…” மெனு: திருத்து, அமைப்பைத் திற, URLஐ நகலெடு, இயக்கு அல்லது முடக்கு, அகற்று.
  • வரிசை முக்கியம்: மூலம் 1 முதலில் கேட்கப்படும். ⋮⋮ கைப்பிடி அல்லது ↑ ↓ அம்புகள் மூலம் அதை மாற்று.
  • நிறுவல் நீக்க: அகற்று, பிறகு “சேமி”.
  • debrid சாவி Laststream-இல் உள்ளிடப்படுவதில்லை: ஒவ்வொரு துணை நிரலும் அதன் சொந்த அமைப்பில் debrid-ஐக் கையாளும்.

எடுத்துக்காட்டு: ஒரு அடிப்படை துணை நிரல்

ஒரு துணை நிரல் என்பது இரண்டு முகவரிகளை வெளிப்படுத்தும் ஒரு சிறிய இணையச் சேவை: /manifest.json மற்றும் /stream/{type}/{id}.json.

மேனிஃபெஸ்ட்:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json இன் பதில்:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

இந்த வழிகாட்டியின் திரைப்பிடிப்புகளுக்குப் பயன்படுத்தப்பட்ட அதே துணை நிரல் இதுதான்.

முந்தைய வழிகாட்டி குழந்தைகள் சுயவிவரத்தை உருவாக்கு அடுத்த வழிகாட்டி நேரலை தொலைக்காட்சியை அமை (M3U பட்டியல்)
Laststream

Laststream எந்த உள்ளடக்கத்தையும் வழங்குவதில்லை: நீங்கள் அமைக்கும் துணை நிரல்களைப் படிக்கிறது. அழைப்பு மூலம் மட்டும்.

வழிகாட்டிகள்

Laststream, Stremio உடன் இணைக்கப்படவில்லை.

இந்தத் தயாரிப்பு TMDB API ஐப் பயன்படுத்துகிறது, ஆனால் TMDB-ஆல் ஒப்புதல் அளிக்கப்படவோ சான்றளிக்கப்படவோ இல்லை.

டெமோ பட்டியலுடன் எடுக்கப்பட்ட திரைப்பிடிப்புகள்: கற்பனைத் தலைப்புகளும் AI உருவாக்கிய போஸ்டர்களும்.
