நேரலை தொலைக்காட்சியை அமை (M3U பட்டியல்)

நேரலை தொலைக்காட்சி, உங்கள் வழங்குநர் அல்லது IPTV சேவையிலிருந்து M3U பட்டியல்களையும், விரும்பினால் XMLTV நிரல் வழிகாட்டியையும் படிக்கிறது.

  • 5 நிமிடங்கள்
  • Windows
  • Android

தொடங்குவதற்கு முன்

  • Windows அல்லது Android செயலி: பெரும்பாலான பட்டியல்களை உலாவியால் அணுக முடியாது.
  • உங்கள் M3U பட்டியல் முகவரி (உங்களிடம் இருந்தால் XMLTV வழிகாட்டி முகவரியும்).

படிகள்

ஒவ்வொரு திரைப்பிடிப்பிலும், மஞ்சள் சட்டம் எங்கு தட்ட அல்லது கிளிக் செய்ய வேண்டும் என்பதைக் காட்டுகிறது; எண்கள் வரிசையைத் தருகின்றன. செயலி பிரெஞ்சு மொழியில் உள்ளது: திரைப்பிடிப்புகள் அதன் ஆங்கில மொழிபெயர்ப்பைக் காட்டுகின்றன.

  1. உங்கள் அவதாரைத் தட்டு, பிறகு “அமைப்புகள்”, பிறகு இடது நெடுவரிசையில் “நேரலை தொலைக்காட்சி”.

  2. “M3U பட்டியலைச் சேர்” இல், பெயரை நிரப்பு (1, விருப்பத்தேர்வு), “பட்டியல் முகவரியை” (2) மற்றும் உங்களிடம் இருந்தால் “நிரல் வழிகாட்டி (XMLTV)” (3, .xml அல்லது .xml.gz).

    “பட்டியலைச் சேர்” (4) ஐத் தட்டு. சாதனத்திலிருந்து “கோப்பை இறக்கு” (.m3u) என்பதையும் தேர்ந்தெடுக்கலாம்.

  3. “… சேனல்கள் சேர்க்கப்பட்டன, வழிகாட்டி புதுப்பிக்கப்பட்டது” செய்தி தோன்றியதும், முகப்புக்குத் திரும்பி “நேரலை” தாவலைத் திற.

  4. உங்கள் சேனல்கள் “Box” அடையாளத்துடன், அவற்றின் நிகழ்ச்சிகளுடன் தோன்றும். இடது நெடுவரிசை வகையின்படி வடிகட்டும்.

  5. ஒரு நிகழ்ச்சியின் விவரங்களைப் பார்க்க அதைத் தட்டு, பிறகு “பார்”.

தெரிந்துகொள்ள வேண்டியவை

  • Freebox சந்தாதாரர்: “என் Freebox-ஐக் கண்டறி” எதையும் தட்டச்சு செய்யாமல் பெட்டியின் சேனல்களைச் சேர்க்கும்.
  • ஒவ்வொரு பட்டியலையும் “M3U பட்டியல்கள்” கீழ், அதன் வரிசையிலிருந்து முடக்கலாம், புதுப்பிக்கலாம் அல்லது அகற்றலாம்.
  • கணக்கின் பட்டியல்கள் முதன்மை சுயவிவரத்தால் நிர்வகிக்கப்படும்.

எதிர்பார்க்கப்படும் வடிவம்

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

முதல் வரி #EXTM3U ஆக இருக்க வேண்டும். ஒவ்வொரு #EXTINF வரியையும் ஸ்ட்ரீம் முகவரி பின்தொடரும் (http, https, rtsp, rtp அல்லது udp). group-title வகையையும், tvg-chno எண்ணையும் (1 முதல் 9999 வரை), tvg-id XMLTV வழிகாட்டியுடன் இணைப்பையும் தரும்.

வேலை செய்யவில்லையென்றால்

  • “இந்த முகவரி M3U பட்டியலை வழங்கவில்லை.” → முகவரி ஒரு இணையப் பக்கத்தையோ வேறு வடிவ கோப்பையோ சுட்டுகிறது.
  • “இந்தப் பட்டியலில் சேனல் எதுவும் கிடைக்கவில்லை.” → கோப்பு காலியாக உள்ளது அல்லது தவறான வடிவில் உள்ளது.
  • “முகவரியை அடைய முடியவில்லை” → முகவரியையும் உங்கள் இணைப்பையும் சரிபார்க்கவும் (Freebox எனில் உங்கள் பெட்டியின் பிணையத்தையும்).
  • உலாவியில் → பெரும்பாலான பட்டியல்களை உலாவியால் அணுக முடியாது: Windows அல்லது Android செயலியைப் பயன்படுத்தவும்.
