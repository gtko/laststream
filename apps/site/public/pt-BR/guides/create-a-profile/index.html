Criar um perfil

Cada pessoa da casa tem o próprio perfil: biblioteca, progresso e configurações acompanham em todos os dispositivos.

  • 2 min
  • Windows
  • Android
  • Navegador

Antes de começar

  • Uma conta conectada.
  • Só o perfil principal (ou alguém que conheça o código dele) pode adicionar perfis.

Etapas

Em cada captura de tela, o contorno amarelo mostra onde tocar ou clicar; os números indicam a ordem. O app está em francês: as capturas mostram a tradução para o inglês.

  1. Toque no seu avatar no canto superior direito (1) e depois em “Trocar perfil” (2).

  2. Na tela “Quem está assistindo?”, toque no bloco “Adicionar um perfil”.

  3. Em “Novo perfil”, digite o nome (1, no máximo 20 caracteres). Se quiser, escolha um avatar com “Trocar avatar” (2) e depois uma cor entre as 8 amostras (3).

  4. Opcional: um “Código PIN do perfil” de 4 dígitos (1), pedido a partir de então para abrir este perfil.

    Toque em “Criar perfil” no canto superior direito (2).

  5. O novo perfil aparece ao lado dos outros. Toque em “Concluído” para voltar a “Quem está assistindo?” e depois toque no perfil para abri-lo.

Bom saber

  • Para editar um perfil: “Gerenciar perfis”, depois toque no perfil. Você pode alterar nome, avatar, cor ou código PIN.
  • Para excluir um perfil: mesmo caminho, depois a zona de perigo na parte inferior (digite o nome dele para confirmar). O perfil principal não pode ser excluído.
  • Para uma criança, siga o guia Criar um perfil infantil.

O Laststream não hospeda conteúdo: ele lê as extensões que você configura. Somente por convite.

Guias
