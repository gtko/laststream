स्रोत जोडा (Stremio विस्तार)

Laststream Stremio विस्तार (अ‍ॅड-ऑन) स्वीकारते: त्यांच्या manifest चा पत्ता पेस्ट कर, आणि शीर्षक प्ले करताना त्यांच्या लिंक दिसतात.

  • 3 मिनिटे
  • Windows
  • Android
  • ब्राउझर

सुरू करण्यापूर्वी

  • साइन इन केलेले खाते, मुख्य प्रोफाइलवर.
  • एक्स्टेंशनच्या manifest चा पत्ता (तो सहसा /manifest.json ने संपतो).

टप्पे

प्रत्येक स्क्रीनशॉटवर, पिवळी चौकट कुठे दाबायचे किंवा क्लिक करायचे ते दाखवते; आकडे क्रम देतात. ॲप फ्रेंचमध्ये आहे: स्क्रीनशॉट त्याचा इंग्रजी अनुवाद दाखवतात.

  1. तुमचा अवतार दाबा, मग “सेटिंग्ज”.

  2. डाव्या स्तंभात “स्रोत” (1) निवड, मग “Stremio अ‍ॅड-ऑन जोडा” (2).

  3. पत्ता “Upstream addon URL” मध्ये पेस्ट करा. stremio:// लिंक स्वीकारल्या जातात, आणि नसल्यास /manifest.json जोडले जाते.

    स्क्रीनशॉटवरील पत्ता http://localhost ने सुरू होतो: हे खालील उदाहरण एक्स्टेंशन आहे, मार्गदर्शकासाठी स्थानिक पातळीवर चालवलेले. तुम्हाला इंस्टॉल करायचे असलेल्या एक्स्टेंशनने दिलेला पत्ता तुम्ही पेस्ट करता.

  4. manifest लगेच वाचले जाते: अ‍ॅड-ऑनचे नाव, लोगो आणि स्थिती दिसते (1). सेटिंग्जच्या तळाशी “जतन करा” दाबा (2).

  5. चित्रपट उघडा आणि “प्ले” दाबा: अ‍ॅड-ऑनच्या लिंक “स्रोत” पॅनलमध्ये दिसतात.

माहीत असणे चांगले

  • कार्डचा “…” मेनू: संपादित कर, कॉन्फिगरेशन उघड, URL कॉपी कर, सुरू किंवा बंद कर, काढ.
  • क्रम महत्त्वाचा आहे: स्रोत 1 प्रथम तपासला जातो. ⋮⋮ हँडल किंवा ↑ ↓ बाणांनी तो बदला.
  • अनइंस्टॉल करण्यासाठी: काढा, मग “जतन करा”.
  • डेब्रिड की Laststream मध्ये टाकलेली नाही: प्रत्येक अ‍ॅड-ऑन डेब्रिड स्वतःच्या कॉन्फिगरेशनमध्ये हाताळतो.

उदाहरण: एक साधा विस्तार

विस्तार ही एक छोटी वेब सेवा आहे जी दोन पत्ते उघड करते: /manifest.json आणि /stream/{type}/{id}.json.

manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json चा प्रतिसाद:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

या मार्गदर्शकाच्या स्क्रीनशॉटसाठी वापरलेले हेच एक्स्टेंशन आहे.

मागील मार्गदर्शक मुलांसाठी प्रोफाइल तयार कर पुढील मार्गदर्शक लाइव्ह टीव्ही सेट कर (M3U प्लेलिस्ट)

मार्गदर्शक

Laststream चा Stremio शी संबंध नाही.
