लाइव्ह टीव्ही सेट करा (M3U प्लेलिस्ट)

लाइव्ह टीव्ही तुझ्या प्रदात्याकडून किंवा IPTV सेवेकडून M3U प्लेलिस्ट वाचते, आणि ऐच्छिक XMLTV कार्यक्रम मार्गदर्शक.

  • 5 मिनिटे
  • Windows
  • Android

सुरू करण्यापूर्वी

  • Windows किंवा Android ॲप: ब्राउझर बहुतेक प्लेलिस्टपर्यंत पोहोचू शकत नाही.
  • तुमचा M3U प्लेलिस्ट पत्ता (आणि तुमच्याकडे असल्यास, XMLTV मार्गदर्शकाचा पत्ता).

टप्पे

प्रत्येक स्क्रीनशॉटवर, पिवळी चौकट कुठे दाबायचे किंवा क्लिक करायचे ते दाखवते; आकडे क्रम देतात. ॲप फ्रेंचमध्ये आहे: स्क्रीनशॉट त्याचा इंग्रजी अनुवाद दाखवतात.

  1. तुमचा अवतार दाबा, मग “सेटिंग्ज”, मग डाव्या स्तंभातील “लाइव्ह टीव्ही”.

  2. “M3U प्लेलिस्ट जोडा” मध्ये नाव (1, ऐच्छिक), “प्लेलिस्ट पत्ता” (2) भर आणि तुझ्याकडे असल्यास “कार्यक्रम मार्गदर्शक (XMLTV)” (3, .xml किंवा .xml.gz).

    “प्लेलिस्ट जोडा” (4) दाबा. डिव्हाइसवरून “फाइल आयात करा” (.m3u) देखील करता येते.

  3. “… चॅनेल जोडले, मार्गदर्शक अपडेट झाले” संदेश दिसल्यावर, होमवर परत जा आणि “लाइव्ह” टॅब उघडा.

  4. तुमचे चॅनेल “बॉक्स” बॅजसह, त्यांच्या कार्यक्रमांसह दिसतात. डावा स्तंभ प्रकारानुसार फिल्टर करतो.

  5. तपशील पाहण्यासाठी कार्यक्रमावर दाबा, मग “पहा”.

माहीत असणे चांगले

  • Freebox ग्राहक: “माझा Freebox शोध” काहीही टाईप न करता बॉक्सचे चॅनेल जोडतो.
  • प्रत्येक प्लेलिस्ट “M3U प्लेलिस्ट” अंतर्गत तिच्या ओळीतून बंद, रिफ्रेश किंवा काढली जाऊ शकते.
  • खात्याच्या प्लेलिस्ट मुख्य प्रोफाइलद्वारे व्यवस्थापित केल्या जातात.

अपेक्षित स्वरूप

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

पहिली ओळ #EXTM3U असणे आवश्यक आहे. प्रत्येक #EXTINF नंतर स्ट्रीम पत्ता येतो (http, https, rtsp, rtp किंवा udp). group-title प्रकार देतो, tvg-chno क्रमांक (1 ते 9999), tvg-id XMLTV मार्गदर्शकाशी जोडतो.

काम न केल्यास

  • “हा पत्ता M3U प्लेलिस्ट परत देत नाही.” → पत्ता वेब पेज किंवा दुसऱ्या स्वरूपातील फाईलकडे निर्देश करतो.
  • “या प्लेलिस्टमध्ये कोणताही चॅनेल सापडला नाही.” → फाईल रिकामी किंवा चुकीच्या स्वरूपाची आहे.
  • “पत्त्यापर्यंत पोहोचता येत नाही” → पत्ता आणि तुझे कनेक्शन तपास (आणि Freebox साठी तुझ्या बॉक्सचे नेटवर्क).
  • ब्राउझरमध्ये → वेब ब्राउझर बहुतेक प्लेलिस्टपर्यंत पोहोचू शकत नाही: Windows किंवा Android अ‍ॅप वापर.
