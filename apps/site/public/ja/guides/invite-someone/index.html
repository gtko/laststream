友だちを招待する

登録は招待制です。招待チケットを1枚贈ってください。メッセージと、見てほしい3つのタイトルを添えた個人リンクになります。

  • 2分
  • Windows
  • Android
  • ブラウザ

始める前に

  • サインイン済みのアカウントと、大人のプロフィール。
  • お気に入りを提案したい場合は、ライブラリにいくつかタイトルを入れておきましょう。

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. 「設定」（右上のアバター）の「プロフィール」カテゴリを開きます。「マイ招待チケット」をタップすると、チケットが表示されます。

  2. 未使用のチケットを選び、「このチケットを贈る」を押します。

  3. メッセージを書きます（1、最大280文字）。相手のウェルカムページに表示されます。ライブラリからお気に入りを最大3件選びます（2）。

    「リンクをコピー」（3）をタップするか、「共有…」を選んでスマートフォンから直接送ります。

  4. リンクはお好きな方法で送ってください（メッセージ、メールなど）。チケットは、相手がアカウントを作成するまで「送信済み、保留中」と表示されます。

知っておくと便利

  • チケットは1回限り有効です。リンクは送信後14日間有効です。誰も使わなかった場合、チケットはご自身に戻ります。
  • 間違った相手を選んでしまった場合は、「チケットを取り消す」ですぐに戻せます。
  • 招待した相手は、ワンクリックで友だちになれます。メッセージなしでより手早く行うには、友だちパネルの「友だちを招待する」「リンクをコピー」を使います。
  • （同じ世帯の人に）プロフィールへのアクセスを与えるには、すぐ下の「世帯の招待」カードを使います。
前のガイド ライブテレビを設定する（M3Uプレイリスト） 次のガイド Stremioのライブラリをインポートする
Laststream

Laststreamはコンテンツをホストしません。設定されたアドオンを読み取るだけです。招待制です。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
