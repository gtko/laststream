ソースを追加（Stremioアドオン）

LaststreamはStremioアドオンに対応しています。マニフェストのアドレスを貼り付けると、タイトルを再生したときにそのリンクが表示されます。

  • 3分
  • Windows
  • Android
  • ブラウザ

始める前に

  • サインイン済みのアカウントと、メインプロフィール。
  • アドオンのマニフェストのアドレス（通常は /manifest.json で終わります）。

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. アバターをタップし、「設定」を選びます。

  2. 左の列で「ソース」（1）を選び、「Stremioアドオンを追加」（2）を選びます。

  3. アドレスを「上流アドオンのURL」に貼り付けます。stremio:// のリンクも使えます。/manifest.json がない場合は自動で追加されます。

    スクリーンショットのアドレスは http://localhost で始まっています。これは、このガイド用にローカルで動かしている下の例のアドオンです。インストールしたいアドオンが提供するアドレスを貼り付けてください。

  4. マニフェストはすぐに読み込まれ、アドオンの名前、ロゴ、状態が表示されます（1）。設定の下部にある「保存」をタップします（2）。

  5. 映画を開いて「再生」をタップすると、アドオンのリンクが「ソース」パネルに表示されます。

知っておくと便利

  • カードの「…」メニュー：編集、設定を開く、URLをコピー、有効化・無効化、削除。
  • 順番が重要です。ソース1が最初に検索されます。⋮⋮のハンドル、または ↑ ↓ の矢印で並べ替えられます。
  • アンインストールするには、削除してから「保存」を押します。
  • DebridのキーはLaststreamには入力しません。各アドオンが、それぞれの設定でDebridを扱います。

例：基本的なアドオン

アドオンとは、2つのアドレス /manifest.json と /stream/{type}/{id}.json を公開する小さなWebサービスです。

マニフェスト：

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json のレスポンス：

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

これは、このガイドのスクリーンショットで使用したアドオンそのものです。

前のガイド キッズプロフィールを作成する 次のガイド ライブテレビを設定する（M3Uプレイリスト）
Laststream

Laststreamはコンテンツをホストしません。設定されたアドオンを読み取るだけです。招待制です。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
