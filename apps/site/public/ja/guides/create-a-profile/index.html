プロフィールを作成する

家族それぞれが自分のプロフィールを持てます。ライブラリ、再生の続き、設定は、すべての端末で引き継がれます。

  • 2分
  • Windows
  • Android
  • ブラウザ

始める前に

  • サインイン済みのアカウント。
  • プロフィールを追加できるのは、メインプロフィール（またはそのコードを知っている人）だけです。

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. 右上のアバター（1）をタップし、「プロフィールを切り替える」（2）を選びます。

  2. 「視聴しているのは誰ですか？」の画面で、「プロフィールを追加」のタイルをタップします。

  3. 「新しいプロフィール」で名前を入力します（1、最大20文字）。必要に応じて「アバターを変更」（2）でアバターを選び、8色のカラーから色を選びます（3）。

  4. 任意：4桁の「プロフィールPINコード」（1）。設定後は、このプロフィールを開くときにコードが求められます。

    右上の「プロフィールを作成」（2）をタップします。

  5. 新しいプロフィールが他のプロフィールと並んで表示されます。「完了」をタップして「視聴しているのは誰ですか？」に戻り、プロフィールをタップして開きます。

知っておくと便利

  • プロフィールを編集するには、「プロフィールを管理」を選び、プロフィールをタップします。名前、アバター、色、PINコードを変更できます。
  • プロフィールを削除するには、同じ手順で、下部の「危険な操作」を開きます（確認のため名前を入力）。メインプロフィールは削除できません。
  • お子さまの場合は、キッズプロフィールを作成するガイドに従ってください。
次のガイド キッズプロフィールを作成する
Laststream

Laststreamはコンテンツをホストしません。設定されたアドオンを読み取るだけです。招待制です。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
