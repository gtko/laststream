ライブテレビを設定する（M3Uプレイリスト）

ライブテレビは、プロバイダーやIPTVサービスのM3Uプレイリストと、任意でXMLTV番組表を読み込みます。

  • 5分
  • Windows
  • Android

始める前に

  • WindowsまたはAndroidアプリをご利用ください。ブラウザでは多くのプレイリストに接続できません。
  • M3Uプレイリストのアドレス（お持ちの場合はXMLTV番組表のアドレス）。

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. アバターをタップし、「設定」を選び、左の列で「ライブテレビ」を選びます。

  2. 「M3Uプレイリストを追加」で、名前（1、任意）、「プレイリストのアドレス」（2）、お持ちの場合は「番組表（XMLTV）」（3、.xml または .xml.gz）を入力します。

    「プレイリストを追加」（4）をタップします。端末から.m3uファイルを「ファイルをインポート」することもできます。

  3. 「…件のチャンネルを追加し、番組表を更新しました」と表示されたら、ホームに戻り、「ライブ」タブを開きます。

  4. チャンネルは、番組とともに「ボックス」バッジ付きで表示されます。左の列でカテゴリごとに絞り込めます。

  5. 番組をタップして詳細を確認し、「視聴」を押します。

知っておくと便利

  • Freeboxの契約者の方：「Freeboxを検出」を押すと、入力なしでボックスのチャンネルが追加されます。
  • 各プレイリストは「M3Uプレイリスト」の行から、無効化、更新、削除できます。
  • アカウントのプレイリストは、メインプロフィールで管理されます。

想定される形式

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

1行目は #EXTM3U である必要があります。各 #EXTINF の後に、ストリームのアドレス（http、https、rtsp、rtp、udp）が続きます。group-title はカテゴリ、tvg-chno は番号（1〜9999）、tvg-id はXMLTV番組表との紐付けに使います。

上限値
プレイリストのサイズ20 MB
読み込みタイムアウト20 s
自動更新24時間ごと
アカウントごとのプレイリスト数20
番組表今から +24時間

うまくいかない場合

  • 「このアドレスはM3Uプレイリストを返しません。」 → アドレスがWebページ、または別形式のファイルを指しています。
  • 「このプレイリストにチャンネルがありません。」 → ファイルが空か、形式が正しくありません。
  • 「アドレスに接続できません」 → アドレスと接続を確認してください（Freeboxの場合はボックスのネットワークも確認）。
  • ブラウザで → Webブラウザでは多くのプレイリストに接続できないため、WindowsまたはAndroidアプリをご利用ください。

アプリはこれらのメッセージをフランス語で表示します。

前のガイド ソースを追加（Stremioアドオン） 次のガイド 友だちを招待する
Laststream

Laststreamはコンテンツをホストしません。設定されたアドオンを読み取るだけです。招待制です。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
