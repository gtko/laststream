Stremioのライブラリをインポートする

Stremioのライブラリ、視聴済みタイトル、再生の続きをLaststreamのプロフィールに取り込みます。インポートはアカウントを読み取るだけで、変更することはありません。

  • 3分
  • Windows
  • Android
  • ブラウザ

始める前に

  • Stremioのメールアドレスとパスワード、またはStremioのエクスポートファイル。
  • タイトルを取り込む先のLaststreamプロフィールを開いた状態。

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. 「設定」の「プロフィール」カテゴリを開き、「他のアプリからインポート」までスクロールします。

  2. 「Stremioアカウント」（1）を選びます。アカウントにサインインせずに使いたい場合は、「Stremioエクスポートファイル」（2）でこの端末内のファイルを読み込めます。

  3. お知らせを読み、「わかりました、続行」をタップします。

    Stremioのメールアドレス（1）とパスワード（2）を入力し、「ライブラリを読み込む」（3）を押します。

  4. Laststreamは取り込める項目を表示します：「ライブラリ」「ウォッチリスト」「視聴済み」「再生の続き」。不要な項目のチェックを外し（1）、「インポート」（2）を押してください。

  5. 最後に、まとめで取り込み、スキップ、失敗した項目が表示されます。「マイライブラリを見る」をタップしてください。

  6. Stremioのタイトルが、視聴状況と再生の続きとともにライブラリに入ります。

知っておくと便利

  • メールアドレスとパスワードは、お使いの端末から直接Stremioに送られます。Laststreamもサーバーも受け取らず、保存もされません。
  • Stremioアカウントには何も変更されません。これまでどおりご利用いただけます。
  • 一致しないタイトル（テレビチャンネル、アドオンのみのタイトル）はスキップされ、レポートに理由が表示されます。コピーやダウンロードができます。
  • 同じカードから、Nuvioのバックアップ、Simklのエクスポート、Plexサーバーの履歴もインポートできます。インポートは開いているプロフィールに入るため、プロフィールごとに繰り返してください。

Laststream

Laststreamはコンテンツをホストしません。設定されたアドオンを読み取るだけです。招待制です。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
