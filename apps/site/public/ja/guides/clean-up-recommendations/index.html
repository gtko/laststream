おすすめを整理する

タイトルやジャンルに興味がない場合は、ホームから削除できます。検索やそのページからは引き続き見つけられます。

  • 2分
  • Windows
  • Android
  • ブラウザ

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. ホームで、ポスターの「…」をタップ（または右クリック、長押し）し、「再度おすすめしない」を選びます。

  2. タイトルページで、再生ボタン横の「…」ボタンから…

  3. …次に「ホームに表示しない」。

  4. 「設定」の「ホーム」カテゴリでは、「非表示のタイトル」（1）に削除したタイトルの数が表示され、「管理」で元に戻せます。

    「おすすめしないジャンル」で、ジャンル（2）をタップすると、そのジャンルのタイトルがすべてホームから外れます。「すべてリセット」で元に戻せます。

知っておくと便利

  • 90%まで再生した映画や、全話視聴したシリーズは、ホームに表示されなくなります。ライブラリ、検索、各ページには残ります。
  • この設定は、開いているプロフィールにのみ適用されます。

Laststream

Laststreamはコンテンツをホストしません。設定されたアドオンを読み取るだけです。招待制です。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
