友だちを追加

各プロフィールにはName#TAGがあります。友だちと交換すると、オンラインの人が分かり、チャットやウォッチパーティーを始められます。

  • 2分
  • Windows
  • Android
  • ブラウザ

始める前に

  • サインイン済みのアカウントと、大人のプロフィール。
  • 友だちのName#TAG（同じ場所で確認できます）。

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. 右上の「友だち」ボタンをタップします。

  2. パネルの上部には、ご自身のName#TAG（1）が表示されます。タップしてコピーし、友だちに送ってください。下の欄（2）には友だちのものを入力します。

  3. 友だちのName#TAGを、タグの文字も含めて正確に入力し（1）、追加ボタン（2）をタップします。

  4. リクエストは「リクエスト」の下に「リクエスト送信済み」と表示されます。

  5. 友だちの側では、友だちパネルにあなたのリクエストが表示され、チェックマークで承認できます。

  6. 完了：友だちがリストに追加され、その状態（「オンライン」など）が表示されます。

知っておくと便利

  • パネルの「メッセージ」と「アクティビティ」タブでは、チャットや友だちが見ている内容を確認できます。
  • 名前の下のステータスをタップして、「退席中」「取り込み中」「オフライン表示」に切り替えられます。
  • チケットで招待した相手は、Name#TAGを交換しなくても、ワンクリックで友だちになれます。
  • キッズプロフィールには友だちもメッセージもありません。

ガイド

Laststreamは Stremioとは提携していません。

この製品はTMDB APIを使用していますが、TMDBによる推奨または認定を受けたものではありません。

デモ用のカタログで作成したスクリーンショットです。タイトルは架空のもので、ポスターはAIで生成されています。
