快適な再生

即時再生、回線に合わせた画質、オープニングのスキップ、連続再生。再生をより快適にする設定です。

  • 2分
  • Windows
  • Android
  • ブラウザ

手順

各スクリーンショットで、黄色の枠はタップまたはクリックする場所を示し、番号は操作の順番を示します。アプリのUIはフランス語です。スクリーンショットは英語訳を表示しています。

  1. 「設定」の「再生」カテゴリ（1）を開きます。「最適なソースで開始」（2）を有効にすると、ソースの一覧を経由せずに再生が始まります。

  2. 「最大解像度」（1）は、データ通信量を抑えるために自動で選ばれる画質に上限を設けます。「回線速度」（2）は、ご自身の回線に重すぎるソースを除外します。「自動（測定値）」のままにするか、速度を選んでください。

  3. シリーズの場合：「オープニングをスキップ」（1）は検出されたときにオープニングを飛ばし、「次のエピソードを再生」（2）はエンディング後に次話を始めます。「あらすじをスキップ」は「前回のあらすじ」を飛ばします。

  4. 遅いソースで再生がかくつく場合は、「バッファサイズ」を「大」または「最大」に上げてください。

知っておくと便利

  • 最大解像度の設定があっても、手動で別のソースを選ぶことはできます。
  • 「接続をテスト」で、すぐに速度を測定します。
  • Androidでは、大きなバッファにすると再生開始とシークがわずかに遅れます（最大では30秒まで）。次回の再生から適用されます。
  • アニメ：「フィラーをスキップ」を有効にすると、連続再生時にフィラーエピソードを飛ばします。
