Dodaj izvor (Stremio dodatak)

Laststream prihvaća Stremio dodatke (addons): zalijepi adresu njihovog manifesta i njihove poveznice se pojave kad pustiš naslov.

  • 3 min
  • Windows
  • Android
  • Preglednik

Prije nego počneš

  • Prijavljen račun, na glavnom profilu.
  • Adresa manifesta dodatka (obično završava s /manifest.json).

Koraci

Na svakoj snimci zaslona žuti okvir pokazuje gdje dodirnuti ili kliknuti; brojevi daju redoslijed. Aplikacija je na francuskom: snimke prikazuju njen engleski prijevod.

  1. Dodirni svoj avatar, zatim „Postavke“.

  2. U lijevom stupcu odaberi „Izvori“ (1), zatim „Dodaj Stremio dodatak“ (2).

  3. Zalijepi adresu u „URL uzvodnog dodatka“. Prihvaćaju se stremio:// poveznice, a /manifest.json se dodaje ako nedostaje.

    Na snimkama adresa počinje s http://localhost: to je primjer dodatka u nastavku, pokrenut lokalno za vodič. Zalijepi adresu koju ti daje dodatak koji želiš instalirati.

  4. Manifest se odmah čita: ime dodatka, logo i status se prikazuju (1). Dodirni „Spremi“ na dnu Postavki (2).

  5. Otvori film i dodirni „Reprodukcija“: poveznice dodatka pojavljuju se u panelu „Izvori“.

Dobro je znati

  • Izbornik „…“ na kartici: uredi, otvori konfiguraciju, kopiraj URL, omogući ili onemogući, ukloni.
  • Redoslijed je važan: izvor 1 se pita prvi. Promijeni ga ručkom ⋮⋮ ili strelicama ↑ ↓.
  • Za deinstalaciju: ukloni, zatim „Spremi“.
  • Debrid ključ se ne unosi u Laststream: svaki dodatak upravlja debridom u vlastitoj konfiguraciji.

Primjer: jednostavan dodatak

Dodatak je mala web usluga koja izlaže dvije adrese: /manifest.json i /stream/{type}/{id}.json.

Manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Odgovor /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Ovo je upravo dodatak korišten za snimke ovog vodiča.
