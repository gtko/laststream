ساخت نمایه

هر کس در خانه نمایه خودش را دارد: کتابخانه، پیشرفت و تنظیماتش در همه دستگاه‌هایش همراهش است.

  • ۲ دقیقه
  • Windows
  • Android
  • مرورگر

قبل از شروع

  • یک حساب واردشده.
  • فقط نمایه اصلی (یا کسی که کدش را می‌داند) می‌تواند نمایه اضافه کند.

مراحل

در هر تصویر، کادر زرد نشان می‌دهد کجا لمس یا کلیک کنید؛ شماره‌ها ترتیب را نشان می‌دهند. برنامه به زبان فرانسوی است: تصاویر ترجمه انگلیسی آن را نشان می‌دهند.

  1. روی آواتار خود بالا سمت راست (۱) بزنید، سپس «تغییر نمایه» (۲).

  2. در صفحه «چه کسی تماشا می‌کند؟»، روی کاشی «افزودن نمایه» بزنید.

  3. در «نمایه جدید»، نامش را وارد کنید (۱، حداکثر ۲۰ نویسه). اگر خواستید، با «تغییر آواتار» (۲) یک آواتار انتخاب کنید، سپس یک رنگ از ۸ نمونه (۳).

  4. اختیاری: یک «کد PIN نمایه» ۴ رقمی (۱) که از این به بعد برای باز کردن این نمایه پرسیده می‌شود.

    روی «ساخت نمایه» بالا سمت راست (۲) بزنید.

  5. نمایه جدید کنار بقیه ظاهر می‌شود. برای برگشت به «چه کسی تماشا می‌کند؟» روی «تمام» بزنید، سپس برای باز کردن، روی نمایه بزنید.

خوب است بدانید

  • برای ویرایش نمایه: «مدیریت نمایه‌ها»، سپس روی نمایه بزنید. می‌توانید نام، آواتار، رنگ یا کد PIN آن را تغییر دهید.
  • برای حذف نمایه: همان مسیر، سپس بخش خطر در پایین (برای تأیید نامش را تایپ کنید). نمایه اصلی قابل حذف نیست.
  • برای کودک، راهنمای ساخت نمایه کودکان را دنبال کنید.

Laststream

Laststream هیچ محتوایی میزبانی نمی‌کند: افزونه‌هایی را می‌خواند که تنظیم می‌کنید. فقط با دعوت.

راهنماها

Laststream به Stremio وابسته نیست.

این محصول از API ‏TMDB استفاده می‌کند، اما مورد تأیید یا گواهی TMDB نیست.

تصاویر با کاتالوگ نمونه گرفته شده‌اند: عنوان‌های ساختگی و پوسترهای ساخت هوش مصنوعی.
