افزودن منبع (افزونه Stremio)

Laststream افزونه‌های Stremio را می‌پذیرد: نشانی manifest آن‌ها را بچسبانید تا پیوندهایشان وقتی عنوانی را پخش می‌کنید ظاهر شوند.

  • ۳ دقیقه
  • Windows
  • Android
  • مرورگر

قبل از شروع

  • یک حساب واردشده، در نمایه اصلی.
  • نشانی manifest افزونه (معمولاً با /manifest.json تمام می‌شود).

مراحل

در هر تصویر، کادر زرد نشان می‌دهد کجا لمس یا کلیک کنید؛ شماره‌ها ترتیب را نشان می‌دهند. برنامه به زبان فرانسوی است: تصاویر ترجمه انگلیسی آن را نشان می‌دهند.

  1. روی آواتارتان بزنید، سپس «تنظیمات».

  2. در ستون چپ، «منابع» (۱) را انتخاب کنید، سپس «افزودن افزونه Stremio» (۲).

  3. نشانی را در «نشانی افزونه بالادستی» بچسبانید. پیوندهای stremio:// پذیرفته می‌شوند و در صورت نبود، /manifest.json اضافه می‌شود.

    در تصاویر، نشانی با http://localhost شروع می‌شود: این افزونه نمونه زیر است که برای راهنما به‌صورت محلی اجرا شده. نشانی‌ای را که افزونه موردنظرتان می‌دهد بچسبانید.

  4. manifest بلافاصله خوانده می‌شود: نام، لوگو و وضعیت افزونه ظاهر می‌شوند (۱). پایین تنظیمات روی «ذخیره» بزنید (۲).

  5. یک فیلم را باز کنید و «پخش» را بزنید: پیوندهای افزونه در پنل «منابع» ظاهر می‌شوند.

خوب است بدانید

  • منوی «…» هر کارت: ویرایش، باز کردن پیکربندی، کپی نشانی، فعال یا غیرفعال کردن، حذف.
  • ترتیب مهم است: منبع ۱ زودتر بررسی می‌شود. با دستگیره ⋮⋮ یا فلش‌های ↑ ↓ آن را تغییر دهید.
  • برای حذف نصب: حذف، سپس «ذخیره».
  • کلید debrid در Laststream وارد نمی‌شود: هر افزونه debrid را در پیکربندی خودش مدیریت می‌کند.

نمونه: یک افزونه ساده

افزونه یک سرویس وب کوچک است که دو نشانی ارائه می‌دهد: /manifest.json و /stream/{type}/{id}.json.

manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

پاسخ /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

این دقیقاً همان افزونه‌ای است که برای تصاویر این راهنما استفاده شده.

راهنمای قبلی ساخت نمایه کودکان راهنمای بعدی راه‌اندازی تلویزیون زنده (فهرست M3U)
Laststream

Laststream هیچ محتوایی میزبانی نمی‌کند: افزونه‌هایی را می‌خواند که تنظیم می‌کنید. فقط با دعوت.

راهنماها

Laststream به Stremio وابسته نیست.

این محصول از API ‏TMDB استفاده می‌کند، اما مورد تأیید یا گواهی TMDB نیست.

تصاویر با کاتالوگ نمونه گرفته شده‌اند: عنوان‌های ساختگی و پوسترهای ساخت هوش مصنوعی.
