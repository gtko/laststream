Dodaj źródło (dodatek Stremio)

Laststream obsługuje dodatki Stremio: wklej adres ich manifestu, a ich linki pojawią się przy odtwarzaniu tytułu.

  • 3 min
  • Windows
  • Android
  • Przeglądarka

Zanim zaczniesz

  • Zalogowane konto, na profilu głównym.
  • Adres manifestu dodatku (zwykle kończy się na /manifest.json).

Kroki

Na każdym zrzucie żółta ramka pokazuje, gdzie stuknąć lub kliknąć; numery określają kolejność. Aplikacja jest w języku francuskim: zrzuty ekranu pokazują jej angielskie tłumaczenie.

  1. Stuknij swój awatar, a potem „Ustawienia”.

  2. W lewej kolumnie wybierz „Źródła” (1), a następnie „Dodaj dodatek Stremio” (2).

  3. Wklej adres w polu „Adres źródłowego dodatku”. Linki stremio:// są akceptowane, a /manifest.json jest dodawany, jeśli go brakuje.

    Na zrzutach adres zaczyna się od http://localhost: to przykładowy dodatek poniżej, uruchomiony lokalnie na potrzeby poradnika. Wklejasz adres podany przez dodatek, który chcesz zainstalować.

  4. Manifest jest odczytywany od razu: nazwa dodatku, logo i status się pojawiają (1). Stuknij „Zapisz” na dole Ustawień (2).

  5. Otwórz film i stuknij „Odtwórz”: linki dodatku pojawią się w panelu „Źródła”.

Warto wiedzieć

  • Menu „…” karty: edytuj, otwórz konfigurację, skopiuj adres URL, włącz lub wyłącz, usuń.
  • Kolejność ma znaczenie: źródło 1 jest sprawdzane jako pierwsze. Zmień ją uchwytem ⋮⋮ lub strzałkami ↑ ↓.
  • Aby odinstalować: usuń, a potem „Zapisz”.
  • Klucza debrid nie wpisuje się w Laststream: każdy dodatek obsługuje debrid we własnej konfiguracji.

Przykład: prosty dodatek

Dodatek to mała usługa internetowa udostępniająca dwa adresy: /manifest.json i /stream/{type}/{id}.json.

Manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Odpowiedź /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

To dokładnie ten dodatek, którego użyto do zrzutów ekranu w tym poradniku.

Poradniki

Laststream nie jest powiązany ze Stremio.

Ten produkt korzysta z API TMDB, ale nie jest przez TMDB zatwierdzony ani certyfikowany.

Zrzuty ekranu wykonano na katalogu demonstracyjnym: wymyślone tytuły i plakaty wygenerowane przez AI.
