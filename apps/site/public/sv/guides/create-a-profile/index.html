Skapa en profil

Alla hemma får sin egen profil: deras bibliotek, framsteg och inställningar följer dem på alla deras enheter.

  • 2 min
  • Windows
  • Android
  • Webbläsare

Innan du börjar

  • Ett inloggat konto.
  • Endast huvudprofilen (eller någon som känner till dess kod) kan lägga till profiler.

Steg

På varje skärmbild visar den gula ramen var du ska trycka eller klicka; siffrorna anger ordningen. Appen är på franska: skärmbilderna visar den engelska översättningen.

  1. Tryck på din avatar uppe till höger (1), sedan ”Byt profil” (2).

  2. På skärmen ”Vem tittar?” trycker du på rutan ”Lägg till en profil”.

  3. I ”Ny profil” skriver du deras namn (1, högst 20 tecken). Om du vill väljer du en avatar med ”Byt avatar” (2), sedan en färg från de 8 nyanserna (3).

  4. Valfritt: en 4-siffrig ”PIN-kod för profilen” (1), som sedan efterfrågas för att öppna den här profilen.

    Tryck på ”Skapa profil” uppe till höger (2).

  5. Den nya profilen visas bredvid de andra. Tryck på ”Klar” för att gå tillbaka till ”Vem tittar?”, tryck sedan på profilen för att öppna den.

Bra att veta

  • För att redigera en profil: ”Hantera profiler”, tryck sedan på profilen. Du kan ändra namn, avatar, färg eller PIN-kod.
  • För att radera en profil: samma väg, sedan farozonen längst ned (skriv dess namn för att bekräfta). Huvudprofilen kan inte raderas.
  • För ett barn, följ guiden Skapa en barnprofil i stället.
