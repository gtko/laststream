Дадаць крыніцу (пашырэнне Stremio)

Laststream падтрымлівае пашырэнні Stremio (дадаткі): устаўце адрас іх маніфесту, і іх спасылкі з'явяцца, калі вы прайграеце назву.

  • 3 хв
  • Windows
  • Android
  • Браўзер

Перад пачаткам

  • Уваходжаны ўліковы запіс, на асноўным профілі.
  • Адрас маніфесту пашырэння (звычайна ён заканчваецца на /manifest.json).

Крокі

На кожным скрыншоце жоўтая рамка паказвае, куды націскаць; лічбы задаюць парадак. Праграма на французскай, а на скрыншотах — англійскі пераклад.

  1. Націсніце свой аватар, затым «Налады».

  2. У левай калонцы абярыце «Крыніцы» (1), затым «Дадаць дадатак Stremio» (2).

  3. Устаўце адрас у «URL дадатка-крыніцы». Спасылкі stremio:// прымаюцца, а /manifest.json дадаецца, калі яго няма.

    На скрыншотах адрас пачынаецца з http://localhost: гэта прыклад пашырэння ніжэй, запушчаны лакальна для дапаможніка. Вы ўстаўляеце адрас, які дае пашырэнне, якое хочаце ўсталяваць.

  4. Маніфест чытаецца адразу: з'яўляюцца назва дадатка, логатып і статус (1). Націсніце «Захаваць» унізе налад (2).

  5. Адкрыйце фільм і націсніце «Прайграць»: спасылкі дадатка з'явяцца на панэлі «Крыніцы».

Карысна ведаць

  • Меню «…» на картцы: рэдагаваць, адкрыць налады, скапіяваць URL, уключыць або выключыць, выдаліць.
  • Парадак мае значэнне: крыніца 1 правяраецца першай. Мяняйце парадак ручкай ⋮⋮ або стрэлкамі ↑ ↓.
  • Каб выдаліць: выдаліце, затым «Захаваць».
  • Ключ debrid не ўводзіцца ў Laststream: кожны дадатак апрацоўвае debrid ва ўласных наладах.

Прыклад: просты дадатак

Дадатак — гэта невялікі вэб-сэрвіс, які адкрывае два адрасы: /manifest.json і /stream/{type}/{id}.json.

Маніфест:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Адказ /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Гэта менавіта тое пашырэнне, якое выкарыстоўвалася для скрыншотаў гэтага дапаможніка.

Laststream

Laststream не змяшчае кантэнту: ён чытае пашырэнні, якія вы наладзілі. Толькі па запрашэнні.

Дапаможнікі

Laststream не звязаны са Stremio.

Гэты прадукт выкарыстоўвае API TMDB, але не падтрымліваецца і не сертыфікаваны TMDB.

Скрыншоты зроблены з дэма-каталогам: выдуманыя назвы і пастэры, створаныя ШІ.
