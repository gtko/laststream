Тікелей эфирді орнату (M3U плейлист)

Тікелей эфир провайдеріңнен немесе IPTV қызметінен M3U плейлистерін оқиды, қаласаң XMLTV бағдарлама нұсқаулығын да.

  • 5 мин
  • Windows
  • Android

Бастамас бұрын

  • Windows немесе Android қолданбасы: браузер плейлистердің көбіне қол жеткізе алмайды.
  • M3U плейлистіңің мекенжайы (және болса, XMLTV нұсқаулығының мекенжайы).

Қадамдар

Әр скриншотта сары жақтау басатын немесе шертетін жерді көрсетеді; сандар реттілікті береді. Қолданба француз тілінде: скриншоттарда оның ағылшынша аудармасы көрсетілген.

  1. Аватарыңды бас, содан кейін «Параметрлер», содан кейін сол жақ бағандағы «Тікелей эфир».

  2. «M3U плейлистін қосу» бөлімінде атауын (1, міндетті емес), «Плейлист мекенжайын» (2) және болса, «Бағдарлама нұсқаулығын (XMLTV)» (3, .xml немесе .xml.gz) толтыр.

    «Плейлист қосу» (4) түймесін бас. Сондай-ақ құрылғыдан «Файлды импорттау» (.m3u) мүмкін.

  3. «… арна қосылды, нұсқаулық жаңартылды» хабары шыққан соң, басты бетке оралып, «Тікелей» қойындысын аш.

  4. Арналарың «Box» белгісімен бағдарламаларымен бірге шығады. Сол жақ баған санат бойынша сүзеді.

  5. Бағдарламаны бас және мәліметін көр, содан кейін «Көру».

Білу пайдалы

  • Freebox жазылушысы: «Freebox-ты анықтау» бокс арналарын ешнәрсе терместен қосады.
  • Әр плейлистті «M3U плейлисттері» астында өз жолынан өшіруге, жаңартуға немесе жоюға болады.
  • Аккаунттың плейлистерін негізгі профиль басқарады.

Күтілетін пішім

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

Бірінші жол #EXTM3U болуы керек. Әр #EXTINF артынан ағын мекенжайы келеді (http, https, rtsp, rtp немесе udp). group-title санатты береді, tvg-chno нөмірді (1-ден 9999-ға дейін), tvg-id XMLTV нұсқаулығына сілтейді.

Жұмыс істемесе

  • «Бұл мекенжай M3U плейлистін қайтармайды.» → мекенжай веб-бетке немесе басқа пішімдегі файлға сілтейді.
  • «Бұл плейлистте арна табылмады.» → файл бос немесе дұрыс емес.
  • «Мекенжайға қол жеткізу мүмкін емес» → мекенжайды және байланысты тексер (Freebox үшін боксың желісін де).
  • Браузерде → веб-браузер плейлистердің көбіне қол жеткізе алмайды: Windows немесе Android қолданбасын пайдаланыңыз.
