ਇੱਕ ਸਰੋਤ ਜੋੜ (Stremio ਐਕਸਟੈਂਸ਼ਨ)

Laststream Stremio ਐਕਸਟੈਂਸ਼ਨਾਂ (ਐਡ-ਆਨ) ਕਬੂਲਦੀ ਹੈ: ਉਨ੍ਹਾਂ ਦੇ manifest ਦਾ ਪਤਾ ਚੇਪ, ਅਤੇ ਜਦੋਂ ਤੂੰ ਕੋਈ ਸਿਰਲੇਖ ਚਲਾਏਂ ਤਾਂ ਉਨ੍ਹਾਂ ਦੇ ਲਿੰਕ ਦਿਸਣਗੇ।

  • 3 ਮਿੰਟ
  • Windows
  • Android
  • ਬਰਾਊਜ਼ਰ

ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

  • ਸਾਈਨ ਇਨ ਖਾਤਾ, ਮੁੱਖ ਪ੍ਰੋਫ਼ਾਈਲ ’ਤੇ।
  • ਐਕਸਟੈਂਸ਼ਨ ਦੇ manifest ਦਾ ਪਤਾ (ਆਮ ਤੌਰ ’ਤੇ /manifest.json ਨਾਲ ਖ਼ਤਮ ਹੁੰਦਾ ਹੈ)।

ਕਦਮ

ਹਰ ਸਕਰੀਨਸ਼ਾਟ ’ਤੇ ਪੀਲਾ ਫ਼ਰੇਮ ਦੱਸਦਾ ਹੈ ਕਿ ਕਿੱਥੇ ਟੈਪ ਜਾਂ ਕਲਿੱਕ ਕਰਨਾ ਹੈ; ਨੰਬਰ ਕ੍ਰਮ ਦਿੰਦੇ ਹਨ। ਐਪ ਫ਼ਰਾਂਸੀਸੀ ਵਿੱਚ ਹੈ: ਸਕਰੀਨਸ਼ਾਟ ਇਸ ਦਾ ਅੰਗਰੇਜ਼ੀ ਅਨੁਵਾਦ ਦਿਖਾਉਂਦੇ ਹਨ।

  1. ਆਪਣੇ ਅਵਤਾਰ ’ਤੇ ਟੈਪ ਕਰ, ਫਿਰ «ਸੈਟਿੰਗਾਂ»।

  2. ਖੱਬੇ ਕਾਲਮ ਵਿੱਚ «ਸਰੋਤ» (1) ਚੁਣ, ਫਿਰ «Stremio ਐਡ-ਆਨ ਜੋੜ» (2)।

  3. ਪਤਾ «Upstream addon URL» ਵਿੱਚ ਚੇਪ। stremio:// ਲਿੰਕ ਮਨਜ਼ੂਰ ਹਨ, ਅਤੇ ਜੇ ਨਾ ਹੋਵੇ ਤਾਂ /manifest.json ਜੋੜਿਆ ਜਾਂਦਾ ਹੈ।

    ਸਕਰੀਨਸ਼ਾਟਾਂ ’ਤੇ ਪਤਾ http://localhost ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ: ਇਹ ਹੇਠਾਂ ਦਿੱਤੀ ਉਦਾਹਰਨ ਐਕਸਟੈਂਸ਼ਨ ਹੈ, ਗਾਈਡ ਲਈ ਲੋਕਲ ਚੱਲ ਰਹੀ ਹੈ। ਤੂੰ ਉਹ ਪਤਾ ਚੇਪ ਜੋ ਉਹ ਐਕਸਟੈਂਸ਼ਨ ਦਿੰਦੀ ਹੈ ਜੋ ਤੂੰ ਇੰਸਟਾਲ ਕਰਨੀ ਚਾਹੁੰਦਾ ਹੈਂ।

  4. Manifest ਤੁਰੰਤ ਪੜ੍ਹਿਆ ਜਾਂਦਾ ਹੈ: ਐਡ-ਆਨ ਦਾ ਨਾਂ, ਲੋਗੋ ਅਤੇ ਹਾਲਤ ਦਿਸਦੇ ਹਨ (1)। ਸੈਟਿੰਗਾਂ ਦੇ ਹੇਠਾਂ «ਸੰਭਾਲ» ’ਤੇ ਟੈਪ ਕਰ (2)।

  5. ਕੋਈ ਫ਼ਿਲਮ ਖੋਲ੍ਹ ਅਤੇ «ਚਲਾ» ’ਤੇ ਟੈਪ ਕਰ: ਐਡ-ਆਨ ਦੇ ਲਿੰਕ «ਸਰੋਤ» ਪੈਨਲ ਵਿੱਚ ਦਿਸਦੇ ਹਨ।

ਜਾਣਨ ਯੋਗ

  • ਕਾਰਡ ਦਾ «…» ਮੀਨੂ: ਸੋਧ, ਸੰਰਚਨਾ ਖੋਲ੍ਹ, URL ਕਾਪੀ ਕਰ, ਚਾਲੂ ਜਾਂ ਬੰਦ ਕਰ, ਹਟਾ।
  • ਕ੍ਰਮ ਮਾਇਨੇ ਰੱਖਦਾ ਹੈ: ਸਰੋਤ 1 ਪਹਿਲਾਂ ਪੁੱਛਿਆ ਜਾਂਦਾ ਹੈ। ⋮⋮ ਹੈਂਡਲ ਜਾਂ ↑ ↓ ਤੀਰਾਂ ਨਾਲ ਬਦਲ।
  • ਅਣਇੰਸਟਾਲ ਕਰਨ ਲਈ: ਹਟਾ, ਫਿਰ «ਸੰਭਾਲ»।
  • ਡੈਬਰਿਡ ਕੁੰਜੀ Laststream ਵਿੱਚ ਨਹੀਂ ਭਰੀ ਜਾਂਦੀ: ਹਰ ਐਡ-ਆਨ ਆਪਣੀ ਸੰਰਚਨਾ ਵਿੱਚ ਡੈਬਰਿਡ ਸੰਭਾਲਦਾ ਹੈ।

ਉਦਾਹਰਨ: ਇੱਕ ਸਧਾਰਨ ਐਕਸਟੈਂਸ਼ਨ

ਇੱਕ ਐਕਸਟੈਂਸ਼ਨ ਇੱਕ ਛੋਟੀ ਵੈੱਬ ਸੇਵਾ ਹੈ ਜੋ ਦੋ ਪਤੇ ਦਿੰਦੀ ਹੈ: /manifest.json ਅਤੇ /stream/{type}/{id}.json।

Manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json ਦਾ ਜਵਾਬ:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

ਇਹ ਬਿਲਕੁਲ ਉਹ ਐਕਸਟੈਂਸ਼ਨ ਹੈ ਜੋ ਇਸ ਗਾਈਡ ਦੀਆਂ ਸਕਰੀਨਸ਼ਾਟਾਂ ਲਈ ਵਰਤੀ ਗਈ।

ਪਿਛਲੀ ਗਾਈਡ ਬੱਚਿਆਂ ਦੀ ਪ੍ਰੋਫ਼ਾਈਲ ਬਣਾ ਅਗਲੀ ਗਾਈਡ ਲਾਈਵ ਟੀਵੀ ਸੈੱਟ ਕਰ (M3U ਪਲੇਲਿਸਟ)
Laststream

Laststream ਕੋਈ ਸਮੱਗਰੀ ਹੋਸਟ ਨਹੀਂ ਕਰਦੀ: ਇਹ ਉਹ ਐਕਸਟੈਂਸ਼ਨਾਂ ਪੜ੍ਹਦੀ ਹੈ ਜੋ ਤੂੰ ਸੈੱਟ ਕਰਦਾ ਹੈਂ। ਸਿਰਫ਼ ਸੱਦੇ ਰਾਹੀਂ।

ਗਾਈਡਾਂ

Laststream Stremio ਨਾਲ ਜੁੜੀ ਨਹੀਂ ਹੈ।

ਇਹ ਉਤਪਾਦ TMDB API ਵਰਤਦਾ ਹੈ ਪਰ TMDB ਵੱਲੋਂ ਸਮਰਥਿਤ ਜਾਂ ਪ੍ਰਮਾਣਿਤ ਨਹੀਂ।

ਡੈਮੋ ਕੈਟਾਲੌਗ ਨਾਲ ਬਣੀਆਂ ਸਕਰੀਨਸ਼ਾਟਾਂ: ਬਣਾਏ ਹੋਏ ਸਿਰਲੇਖ ਅਤੇ AI ਨਾਲ ਬਣੇ ਪੋਸਟਰ।
