Iestati tiešraides TV (M3U saraksts)

Tiešraides TV nolasa M3U sarakstus no tava nodrošinātāja vai IPTV pakalpojuma un pēc izvēles XMLTV programmas ceļvedi.

  • 5 min
  • Windows
  • Android

Pirms sākat

  • Windows vai Android lietotne: pārlūkprogramma nevar piekļūt lielākajai daļai sarakstu.
  • Tava M3U saraksta adrese (un, ja tev ir, XMLTV programmas ceļveža adrese).

Soļi

Katrā ekrānuzņēmumā dzeltenais rāmis rāda, kur pieskarties vai noklikšķināt; cipari rāda kārtību. Lietotne ir franču valodā: ekrānuzņēmumi rāda tās angļu tulkojumu.

  1. Pieskaries savam avatāram, tad „Iestatījumi”, tad „Tiešraides TV” kreisajā kolonnā.

  2. Sadaļā „Pievienot M3U sarakstu” ieraksti nosaukumu (1, nav obligāti), „Saraksta adrese” (2) un, ja tev tāda ir, „Programmas ceļvedis (XMLTV)” (3, .xml vai .xml.gz).

    Pieskaries „Pievienot sarakstu” (4). Vari arī „Importēt failu” (.m3u) no ierīces.

  3. Kad parādās ziņojums „… kanāli pievienoti, programma atjaunināta”, atgriezies sākumā un atver cilni „Tiešraide”.

  4. Tavi kanāli parādās ar zīmi „Mājas ierīce”, kopā ar savām programmām. Kreisā kolonna filtrē pēc kategorijas.

  5. Pieskaries programmai, lai redzētu tās detaļas, tad „Skatīties”.

Noderīgi zināt

  • Freebox abonents: „Atklāt manu Freebox” pievieno kastes kanālus, nemaz nerakstot.
  • Katru atskaņošanas sarakstu var atspējot, atsvaidzināt vai noņemt no tā rindas, sadaļā „M3U saraksti”.
  • Konta sarakstus pārvalda galvenais profils.

Paredzētais formāts

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

Pirmajai rindai jābūt #EXTM3U. Katram #EXTINF seko straumes adrese (http, https, rtsp, rtp vai udp). group-title norāda kategoriju, tvg-chno numuru (1 līdz 9999), tvg-id saista ar XMLTV programmas ceļvedi.

Ja tas nedarbojas

  • „Šī adrese neatgriež M3U sarakstu.” → adrese rāda tīmekļa lapu vai failu citā formātā.
  • „Šajā sarakstā nav atrasts neviens kanāls.” → tukšs vai bojāts fails.
  • „Adrese nav sasniedzama” → pārbaudi adresi un savienojumu (un sava mājas ierīces tīklu Freebox gadījumā).
  • Pārlūkprogrammā → tīmekļa pārlūks nevar piekļūt lielākajai daļai sarakstu: izmanto Windows vai Android lietotni.

Lietotne šos paziņojumus rāda franču valodā.
