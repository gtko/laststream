הוספת מקור (תוסף Stremio)

Laststream מקבלת תוספי Stremio: הדבק את כתובת ה-manifest שלהם, והקישורים שלהם מופיעים כשאתה מפעיל כותר.

  • 3 דק׳
  • Windows
  • Android
  • דפדפן

לפני שמתחילים

  • חשבון מחובר, בפרופיל הראשי.
  • הכתובת של ה-manifest של התוסף (בדרך כלל היא מסתיימת ב-/manifest.json).

שלבים

בכל צילום מסך, המסגרת הצהובה מראה איפה להקיש או ללחוץ; המספרים נותנים את הסדר. האפליקציה בצרפתית: צילומי המסך מציגים את התרגום שלה לאנגלית.

  1. הקש על האווטאר שלך, ואז “הגדרות”.

  2. בעמודה השמאלית, בחר “מקורות” (1), ואז “הוסף תוסף Stremio” (2).

  3. הדבק את הכתובת בשדה “כתובת התוסף במקור”. קישורי stremio:// מתקבלים, ו-/manifest.json מתווסף אם הוא חסר.

    בצילומי המסך הכתובת מתחילה ב-http://localhost: זה תוסף הדוגמה שלמטה, שרץ מקומית עבור המדריך. אתה מדביק את הכתובת שנותן התוסף שאתה רוצה להתקין.

  4. ה-manifest נקרא מיד: שם התוסף, הלוגו והסטטוס מופיעים (1). הקש על “שמור” בתחתית ההגדרות (2).

  5. פתח סרט והקש “הפעל”: הקישורים של התוסף מופיעים בלוח “מקורות”.

חשוב לדעת

  • בתפריט “…” של הכרטיס: עריכה, פתיחת התצורה, העתקת הכתובת, הפעלה או השבתה, הסרה.
  • הסדר חשוב: מקור 1 נבדק ראשון. שנה אותו עם הידית ⋮⋮ או עם החיצים ↑ ↓.
  • להסרה: הסר, ואז “שמור”.
  • מפתח ה-Debrid לא מוזן ב-Laststream: כל תוסף מטפל ב-Debrid בתצורה שלו.

דוגמה: תוסף בסיסי

תוסף הוא שירות אינטרנט קטן שחושף שתי כתובות: /manifest.json ו-/stream/{type}/{id}.json.

ה-manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

התשובה של /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

זהו בדיוק התוסף שבו נעשה שימוש לצילומי המסך של המדריך הזה.

המדריך הקודם יצירת פרופיל לילדים המדריך הבא הגדרת טלוויזיה חיה (רשימת השמעה M3U)
Laststream

Laststream לא מאחסנת תוכן: היא קוראת את התוספים שאתה מגדיר. בהזמנה בלבד.

מדריכים

Laststream אינה קשורה ל-Stremio.

המוצר משתמש ב-API של TMDB, אבל אינו מאושר או מוסמך על ידי TMDB.

צילומי המסך נעשו עם קטלוג הדגמה: כותרים מומצאים וכרזות שנוצרו בבינה מלאכותית.
