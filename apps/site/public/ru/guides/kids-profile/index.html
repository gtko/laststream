Создайте детский профиль

Детский профиль показывает только фильмы с известным возрастным рейтингом не выше выбранного. Чтобы выйти, нужен родительский код.

  • 3 мин
  • Windows
  • Android
  • Браузер

Шаги

На каждом скриншоте жёлтая рамка показывает, куда нажать или кликнуть; цифры задают порядок. Приложение на французском: на скриншотах его английский перевод.

  1. Откройте «Новый профиль», как в руководстве Создайте профиль (аватар, «Сменить профиль», «Добавить профиль»), затем введите его имя.

  2. В разделе «Родительский контроль» включите «Детский профиль».

  3. Выберите «Максимальный возраст» (1): 10, 12, 16 или 18 (по умолчанию 12). Отметьте «Разрешённые разделы» (2), см. таблицу ниже.

  4. Если у основного профиля ещё нет родительского кода, введите 4-значный (1). Он защищает от выхода из детского профиля.

    Нажмите «Создать профиль» (2).

  5. Нажмите «Готово», затем детский профиль: его главная показывает только фильмы для его возраста.

Разрешённые разделы

РазделОтмечено по умолчанию
МультфильмыДа
Семейные фильмыДа
Детские сериалыДа
Классика Disney и PixarДа
Аниме для детейДа
Новое для детейДа
Платформы (Disney+, Netflix)Да
Детское ТВНет

Без «Детского ТВ» вкладка «ТВ» скрыта для ребёнка.

Выход из детского профиля

Нажмите на аватар, затем «Сменить профиль»: спросят родительский код.

Полезно знать

  • Фильм без возрастного рейтинга скрыт.
  • Ребёнок не видит «Настройки», «Статистику», друзей и общий доступ к медиатеке.

Руководства

Laststream не связан с Stremio.

Этот продукт использует API TMDB, но не одобрен и не сертифицирован TMDB.

Скриншоты сделаны на демо-каталоге: вымышленные фильмы и постеры, созданные ИИ.
