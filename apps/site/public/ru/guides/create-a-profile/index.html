Создайте профиль

У каждого члена семьи есть свой профиль: медиатека, прогресс и настройки следуют за ним на всех устройствах.

  • 2 мин
  • Windows
  • Android
  • Браузер

Перед началом

  • Вход в аккаунт.
  • Добавлять профили может только основной профиль (или тот, кто знает его код).

Шаги

На каждом скриншоте жёлтая рамка показывает, куда нажать или кликнуть; цифры задают порядок. Приложение на французском: на скриншотах его английский перевод.

  1. Нажмите аватар в правом верхнем углу (1), затем «Сменить профиль» (2).

  2. На экране «Кто смотрит?» нажмите плитку «Добавить профиль».

  3. В «Новом профиле» введите имя (1, не более 20 символов). При желании выберите аватар через «Сменить аватар» (2), затем цвет из 8 вариантов (3).

  4. Необязательно: 4-значный «PIN-код профиля» (1), который будет запрашиваться при открытии этого профиля.

    Нажмите «Создать профиль» в правом верхнем углу (2).

  5. Новый профиль появится рядом с другими. Нажмите «Готово», чтобы вернуться к «Кто смотрит?», затем нажмите профиль, чтобы открыть его.

Полезно знать

  • Чтобы изменить профиль: «Управление профилями», затем нажмите профиль. Можно поменять имя, аватар, цвет или PIN-код.
  • Чтобы удалить профиль: тот же путь, затем «Опасная зона» внизу (введите его имя для подтверждения). Основной профиль удалить нельзя.
  • Для ребёнка следуйте руководству Создайте детский профиль.

Laststream не размещает контент: приложение читает расширения, которые вы настроили. Только по приглашению.

Руководства

Laststream не связан с Stremio.

Этот продукт использует API TMDB, но не одобрен и не сертифицирован TMDB.

Скриншоты сделаны на демо-каталоге: вымышленные фильмы и постеры, созданные ИИ.
