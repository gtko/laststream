Ein Kinderprofil erstellen

Ein Kinderprofil zeigt nur Titel mit bekannter Altersfreigabe, die dem gewählten Alter entspricht oder darunter liegt. Zum Verlassen wird der Elterncode benötigt.

  • 3 Min.
  • Windows
  • Android
  • Browser

Schritte

Auf jedem Screenshot zeigt der gelbe Rahmen, wo getippt oder geklickt werden muss; die Nummern geben die Reihenfolge an. Die App ist auf Französisch: Die Screenshots zeigen ihre englische Übersetzung.

  1. Öffne „Neues Profil“ wie in der Anleitung Ein Profil erstellen (Avatar, „Profil wechseln“, „Profil hinzufügen“), dann gib den Namen ein.

  2. Unter „Elternkontrolle“ aktiviere „Kinderprofil“.

  3. Wähle die „Altersgrenze“ (1): 10, 12, 16 oder 18 (standardmäßig 12). Hake die „Erlaubten Bereiche“ (2) an, siehe Tabelle unten.

  4. Hat das Hauptprofil noch keinen Elterncode, gib einen 4-stelligen ein (1). Er schützt das Verlassen des Kinderprofils.

    Tippe auf „Profil erstellen“ (2).

  5. Tippe auf „Fertig“, dann auf das Kinderprofil: Seine Startseite zeigt nur Titel für sein Alter.

AbschnittStandardmäßig angehakt

Ohne „Kinder-TV“ ist der Tab TV für das Kind ausgeblendet.

Das Kinderprofil verlassen

Tippe auf deinen Avatar, dann auf „Profil wechseln“: Der Elterncode wird abgefragt.

Gut zu wissen

  • Ein Titel ohne Altersfreigabe wird ausgeblendet.
  • Das Kind sieht weder Einstellungen, Statistiken, Freunde noch die Freigabe der Mediathek.
