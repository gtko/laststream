Ein Profil erstellen

Jede Person zu Hause bekommt ihr eigenes Profil: Mediathek, Fortschritt und Einstellungen folgen ihr auf allen Geräten.

  • 2 Min.
  • Windows
  • Android
  • Browser

Bevor du beginnst

  • Ein angemeldetes Konto.
  • Nur das Hauptprofil (oder jemand, der dessen Code kennt) kann Profile hinzufügen.

Schritte

Auf jedem Screenshot zeigt der gelbe Rahmen, wo getippt oder geklickt werden muss; die Nummern geben die Reihenfolge an. Die App ist auf Französisch: Die Screenshots zeigen ihre englische Übersetzung.

  1. Tippe oben rechts auf deinen Avatar (1), dann auf „Profil wechseln“ (2).

  2. Tippe im Bildschirm „Wer schaut?“ auf die Kachel „Profil hinzufügen“.

  3. Im Fenster „Neues Profil“ gib den Namen ein (1, max. 20 Zeichen). Wenn du möchtest, wähle einen Avatar mit „Avatar ändern“ (2), dann eine Farbe aus den 8 Farbfeldern (3).

  4. Optional: ein 4-stelliger „PIN-Code des Profils“ (1), der ab dann beim Öffnen dieses Profils abgefragt wird.

    Tippe oben rechts auf „Profil erstellen“ (2).

  5. Das neue Profil erscheint neben den anderen. Tippe auf „Fertig“, um zu „Wer schaut?“ zurückzukehren, dann auf das Profil, um es zu öffnen.

Gut zu wissen

  • Um ein Profil zu bearbeiten: „Profile verwalten“, dann auf das Profil tippen. Du kannst Namen, Avatar, Farbe oder PIN-Code ändern.
  • Um ein Profil zu löschen: gleicher Weg, dann die Gefahrenzone unten (zur Bestätigung den Namen eingeben). Das Hauptprofil kann nicht gelöscht werden.
  • Für ein Kind folge stattdessen der Anleitung Ein Kinderprofil erstellen.
