Eine Quelle hinzufügen (Stremio-Erweiterung)

Laststream akzeptiert Stremio-Erweiterungen (Add-ons): Füge die Adresse ihres Manifests ein, und ihre Links erscheinen, wenn du einen Titel abspielst.

  • 3 Min.
  • Windows
  • Android
  • Browser

Bevor du beginnst

  • Ein angemeldetes Konto, mit dem Hauptprofil.
  • Die Adresse des Manifests der Erweiterung (sie endet meist mit /manifest.json).

Schritte

Auf jedem Screenshot zeigt der gelbe Rahmen, wo getippt oder geklickt werden muss; die Nummern geben die Reihenfolge an. Die App ist auf Französisch: Die Screenshots zeigen ihre englische Übersetzung.

  1. Tippe auf deinen Avatar, dann auf „Einstellungen“.

  2. Wähle in der linken Spalte „Quellen“ (1), dann „Ein Stremio-Add-on hinzufügen“ (2).

  3. Füge die Adresse in „Upstream-Add-on-URL“ ein. stremio://-Links werden akzeptiert, und /manifest.json wird ergänzt, falls es fehlt.

    Auf den Screenshots beginnt die Adresse mit http://localhost: Es ist die Beispielerweiterung unten, lokal für die Anleitung gestartet. Du fügst die Adresse ein, die dir die Erweiterung deiner Wahl gibt.

  4. Das Manifest wird sofort gelesen: Name, Logo und Status des Add-ons erscheinen (1). Tippe unten in den Einstellungen auf „Speichern“ (2).

  5. Öffne einen Film und tippe auf „Play“: Die Links des Add-ons erscheinen im Panel „Quellen“.

Gut zu wissen

  • Das „…“-Menü einer Karte: bearbeiten, Konfiguration öffnen, URL kopieren, aktivieren oder deaktivieren, entfernen.
  • Die Reihenfolge zählt: Quelle 1 wird zuerst abgefragt. Ändere sie mit dem Griff ⋮⋮ oder den Pfeilen ↑ ↓.
  • Zum Deinstallieren: entfernen, dann „Speichern“.
  • Der Debrid-Schlüssel wird nicht in Laststream eingegeben: Jedes Add-on verwaltet Debrid in seiner eigenen Konfiguration.

Beispiel: eine einfache Erweiterung

Eine Erweiterung ist ein kleiner Webdienst mit zwei Adressen: /manifest.json und /stream/{type}/{id}.json.

Das Manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Antwort von /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Das ist genau die Erweiterung, die für die Screenshots dieser Anleitung verwendet wurde.
