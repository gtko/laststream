新增來源（Stremio 外掛）

Laststream 支援 Stremio 外掛（addons）：貼上其 manifest 位址，播放作品時即會顯示其連結。

  • 3 分鐘
  • Windows
  • Android
  • 瀏覽器

開始之前

  • 已登入的帳號，使用主要個人檔案。
  • 外掛 manifest 的位址（通常以 /manifest.json 結尾）。

步驟

每張截圖中，黃色框線標示要點選或點按的位置，數字則代表順序。應用程式為法文介面：截圖顯示的是其英文翻譯。

  1. 點選頭像，然後選「設定」。

  2. 在左欄選擇「來源」(1)，然後選擇「新增 Stremio 外掛」(2)。

  3. 將位址貼到「上游外掛網址」中。接受 stremio:// 連結，若缺少 /manifest.json 會自動加上。

    截圖中的位址以 http://localhost 開頭：這是下方的範例外掛，為本指南而在本機執行。你要貼上想安裝的外掛所提供的位址。

  4. 系統會立即讀取 manifest：外掛的名稱、標誌與狀態會顯示出來 (1)。點選「設定」底部的「儲存」(2)。

  5. 開啟一部電影並點選「播放」：外掛的連結會出現在「來源」面板中。

小提醒

  • 卡片的「…」選單：編輯、開啟設定、複製網址、啟用或停用、移除。
  • 順序很重要：會先查詢來源 1。可用 ⋮⋮ 把手或 ↑ ↓ 箭頭調整順序。
  • 解除安裝：移除，然後點選「儲存」。
  • Debrid 金鑰不會輸入在 Laststream 中：每個外掛會在各自的設定中處理 Debrid。

範例：基本外掛

外掛是一個小型網路服務，提供兩個位址：/manifest.json 與 /stream/{type}/{id}.json。

manifest：

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json 的回應：

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

這正是本指南截圖所使用的外掛。
