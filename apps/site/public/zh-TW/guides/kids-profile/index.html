建立兒童檔案

兒童檔案只顯示已知分級、且不高於所設年齡的作品。離開時需要家長密碼。

  • 3 分鐘
  • Windows
  • Android
  • 瀏覽器

步驟

每張截圖中，黃色框線標示要點選或點按的位置，數字則代表順序。應用程式為法文介面：截圖顯示的是其英文翻譯。

  1. 依照建立個人檔案指南開啟「新增個人檔案」（頭像、「切換個人檔案」、「新增個人檔案」），然後輸入其名稱。

  2. 在「家長控制」下，開啟「兒童檔案」。

  3. 選擇「最高年齡」(1)：10、12、16 或 18（預設為 12）。勾選「允許的分區」(2)，請見下表。

  4. 若主要個人檔案尚未設定家長密碼，請輸入 4 位數密碼 (1)。此密碼用於保護離開兒童檔案的操作。

    點選「建立個人檔案」(2)。

  5. 點選「完成」，然後點選兒童檔案：其首頁只會顯示符合其年齡的作品。

允許的分區

區段預設勾選
卡通是
家庭電影是
兒童影集是
迪士尼與皮克斯經典是
兒童動畫是
兒童新片是
平台（Disney+、Netflix）是
兒童電視否

若未開啟「兒童電視」，兒童將看不到電視分頁。

離開兒童檔案

點選其頭像，然後選「切換個人檔案」：系統會要求輸入家長密碼。

小提醒

  • 沒有年齡分級的作品會被隱藏。
  • 兒童看不到「設定」、「統計」、好友或片庫分享。
