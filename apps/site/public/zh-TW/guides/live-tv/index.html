設定電視直播（M3U 播放清單）

電視直播會讀取你的供應商或 IPTV 服務提供的 M3U 播放清單，也可以選擇性地讀取 XMLTV 節目表。

  • 5 分鐘
  • Windows
  • Android

開始之前

  • Windows 或 Android 應用程式：瀏覽器無法連上大多數播放清單。
  • 你的 M3U 播放清單位址（若有 XMLTV 節目表，也請填入其位址）。

步驟

每張截圖中，黃色框線標示要點選或點按的位置，數字則代表順序。應用程式為法文介面：截圖顯示的是其英文翻譯。

  1. 點選頭像，然後選「設定」，再選左欄中的「電視直播」。

  2. 在「新增 M3U 播放清單」中，填入名稱 (1，選填)、「播放清單位址」(2)，若有的話，再填入「節目表 (XMLTV)」(3，.xml 或 .xml.gz)。

    點選「新增播放清單」(4)。也可以從裝置上「匯入檔案」（.m3u）。

  3. 出現「已新增 … 個頻道，節目表已更新」訊息後，返回首頁並開啟「直播」分頁。

  4. 你的頻道會附上「媒體盒」標示與其節目。左欄可依分類篩選。

  5. 點選節目以查看詳細資訊，然後點選「觀看」。

小提醒

  • Freebox 用戶：「偵測我的 Freebox」可自動新增機上盒的頻道，無需輸入任何內容。
  • 每個播放清單都可以在「M3U 播放清單」下，於其列中停用、重新整理或移除。
  • 帳號的播放清單由主要個人檔案管理。

預期格式

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

第一行必須是 #EXTM3U。每個 #EXTINF 後面都要接串流位址（http、https、rtsp、rtp 或 udp）。group-title 指定分類，tvg-chno 指定號碼（1 至 9999），tvg-id 則連結至 XMLTV 節目表。

上限數值
播放清單大小20 MB
載入逾時20 s
自動重新整理每 24 小時
每個帳號的播放清單數20
節目表從現在起至 +24 小時

若無法運作

  • 「此位址未回傳 M3U 播放清單。」 → 此位址指向網頁，或指向其他格式的檔案。
  • 「此播放清單中找不到頻道。」 → 檔案是空的或格式錯誤。
  • 「無法連線至此位址」 → 請檢查位址與你的網路連線（若使用 Freebox，也請檢查媒體盒的網路）。
  • 在瀏覽器中 → 網頁瀏覽器無法連上大多數播放清單：請改用 Windows 或 Android 應用程式。

應用程式會以法文顯示這些訊息。
