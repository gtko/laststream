建立個人檔案

家中每個人都有自己的個人檔案：片庫、進度與設定會跟著他們在所有裝置上同步。

  • 2 分鐘
  • Windows
  • Android
  • 瀏覽器

開始之前

  • 已登入的帳號。
  • 只有主要個人檔案（或知道其密碼的人）可以新增個人檔案。

步驟

每張截圖中，黃色框線標示要點選或點按的位置，數字則代表順序。應用程式為法文介面：截圖顯示的是其英文翻譯。

  1. 點選右上角的頭像 (1)，然後選「切換個人檔案」(2)。

  2. 在「誰在觀看？」畫面中，點選「新增個人檔案」方塊。

  3. 在「新增個人檔案」中，輸入其名稱 (1，最多 20 個字元)。如果願意，可透過「更換頭像」(2) 選擇頭像，再從 8 個色塊 (3) 中選擇顏色。

  4. 選填：4 位數的「個人檔案 PIN 碼」(1)，之後開啟此個人檔案時會要求輸入。

    點選右上角的「建立個人檔案」(2)。

  5. 新個人檔案會出現在其他檔案旁。點選「完成」返回「誰在觀看？」，然後點選該檔案即可開啟。

小提醒

  • 編輯個人檔案：選擇「管理個人檔案」，然後點選該檔案。你可以變更其名稱、頭像、顏色或 PIN 碼。
  • 刪除個人檔案：路徑相同，然後前往底部的危險區域（輸入其名稱以確認）。主要個人檔案無法刪除。
  • 若是為孩子設定，請改依照建立兒童檔案指南操作。
