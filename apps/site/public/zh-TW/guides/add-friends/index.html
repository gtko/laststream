新增好友

每個個人檔案都有 Name#TAG。與好友互換後，即可查看誰在線上、聊天並開始同步觀影。

  • 2 分鐘
  • Windows
  • Android
  • 瀏覽器

開始之前

  • 已登入的帳號，使用成人個人檔案。
  • 好友的 Name#TAG（對方在同一處可找到）。

步驟

每張截圖中，黃色框線標示要點選或點按的位置，數字則代表順序。應用程式為法文介面：截圖顯示的是其英文翻譯。

  1. 點選右上角的「好友」按鈕。

  2. 面板頂部是你自己的 Name#TAG (1)：點選即可複製並傳給好友。下方欄位 (2) 用來新增好友的 Name#TAG。

  3. 完整輸入好友的 Name#TAG，包括標籤字母 (1)，然後點選新增按鈕 (2)。

  4. 請求會顯示在「請求」下方，為「已送出請求」。

  5. 在好友那一端，對方會在好友面板中看到你的請求，並點選勾選標記接受。

  6. 完成：好友已出現在你的清單中，並附上其狀態（「線上」…）。

小提醒

  • 面板的「訊息」與「動態」分頁用於聊天，以及查看好友正在看的內容。
  • 點選名稱下方的狀態，即可切換為「離開」、「勿擾」或「隱身」。
  • 你以邀請券邀請的人，只要點一下即可成為你的好友，無需交換 Name#TAG。
  • 兒童檔案沒有好友與訊息功能。
