匯入你的 Stremio 片庫

將你的 Stremio 片庫、已看作品與進度匯入你的 Laststream 個人檔案。匯入只會讀取你的帳號，絕不會更改它。

  • 3 分鐘
  • Windows
  • Android
  • 瀏覽器

開始之前

  • 你的 Stremio 電子郵件與密碼，或 Stremio 匯出檔案。
  • 已開啟、要接收這些作品的 Laststream 個人檔案。

步驟

每張截圖中，黃色框線標示要點選或點按的位置，數字則代表順序。應用程式為法文介面：截圖顯示的是其英文翻譯。

  1. 開啟「設定」、「個人檔案」類別，然後向下捲動至「從其他應用程式匯入」。

  2. 選擇「Stremio 帳號」(1)。若不想登入你的帳號，可使用「Stremio 匯出檔案」(2)讀取此裝置上的檔案。

  3. 閱讀通知，然後點選「知道了，繼續」。

    輸入你的 Stremio 電子郵件 (1) 與密碼 (2)，然後點選「讀取我的片庫」(3)。

  4. Laststream 會顯示可匯入的項目：「片庫」、「待看清單」、「已看」、「播放進度」。取消勾選不需要的項目 (1)，然後點選「匯入」(2)。

  5. 完成後，摘要會列出匯入、略過與失敗的項目。點選「查看我的片庫」。

  6. 你的 Stremio 作品已在片庫中，並附帶觀看狀態與進度。

小提醒

  • 你的電子郵件與密碼會直接從你的裝置傳送至 Stremio。Laststream 與你的伺服器都不會接收，也不會保存。
  • 你的 Stremio 帳號不會有任何變動，你可以照常使用。
  • 找不到對應項目的作品（電視頻道、僅限外掛的作品）會被略過，報告會說明原因。你可以複製或下載報告。
  • 同一張卡片也可以匯入 Nuvio 備份、Simkl 匯出檔案或 Plex 伺服器的紀錄。匯入的內容會進入目前開啟的個人檔案：每個檔案都要分別執行一次。
