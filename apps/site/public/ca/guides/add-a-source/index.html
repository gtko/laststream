Afegeix una font (extensió de Stremio)

Laststream accepta extensions de Stremio (complements): enganxa l’adreça del seu manifest i els seus enllaços apareixeran quan reprodueixis un títol.

  • 3 min
  • Windows
  • Android
  • Navegador

Abans de començar

  • Un compte iniciat, en el perfil principal.
  • L’adreça del manifest de l’extensió (normalment acaba amb /manifest.json).

Passos

A cada captura, el marc groc indica on has de tocar o fer clic; els números donen l’ordre. L’app és en francès: les captures mostren la traducció a l’anglès.

  1. Toca el teu avatar i després «Configuració».

  2. A la columna esquerra, tria «Fonts» (1) i després «Afegeix un complement de Stremio» (2).

  3. Enganxa l’adreça a «URL del complement d’origen». S’accepten enllaços stremio://, i s’afegeix /manifest.json si falta.

    A les captures, l’adreça comença amb http://localhost: és l’extensió d’exemple de sota, executada localment per a la guia. Enganxes l’adreça que et doni l’extensió que vulguis instal·lar.

  4. El manifest es llegeix de seguida: apareixen el nom, el logotip i l’estat del complement (1). Toca «Desa» a la part inferior de la configuració (2).

  5. Obre una pel·lícula i toca «Reprodueix»: els enllaços del complement apareixen al panell «Fonts».

Bon a saber

  • El menú «…» d’una targeta: edita, obre la configuració, copia l’URL, activa o desactiva, elimina.
  • L’ordre importa: la font 1 es consulta primer. Canvia’l amb el control ⋮⋮ o les fletxes ↑ ↓.
  • Per desinstal·lar: elimina i després «Desa».
  • La clau de Debrid no s’introdueix a Laststream: cada complement gestiona Debrid a la seva pròpia configuració.

Exemple: una extensió bàsica

Un complement és un petit servei web que exposa dues adreces: /manifest.json i /stream/{type}/{id}.json.

El manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

Resposta de /stream/movie/tt0000001.json:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

Aquesta és exactament l’extensió usada per a les captures d’aquesta guia.
