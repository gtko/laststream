നിങ്ങളുടെ Stremio ലൈബ്രറി ഇറക്കുമതി ചെയ്യുക

നിങ്ങളുടെ Stremio ലൈബ്രറി, കണ്ട ശീർഷകങ്ങൾ, പുരോഗതി എന്നിവ നിങ്ങളുടെ Laststream പ്രൊഫൈലിലേക്ക് കൊണ്ടുവരിക. ഇറക്കുമതി നിങ്ങളുടെ അക്കൗണ്ട് വായിക്കുന്നു, ഒരിക്കലും മാറ്റം വരുത്തുന്നില്ല.

തുടങ്ങുന്നതിന് മുമ്പ്

  • നിങ്ങളുടെ Stremio ഇമെയിലും പാസ്‌വേഡും, അല്ലെങ്കിൽ ഒരു Stremio എക്സ്പോർട്ട് ഫയൽ.
  • ശീർഷകങ്ങൾ ലഭിക്കേണ്ട Laststream പ്രൊഫൈൽ, തുറന്നത്.

ഘട്ടങ്ങൾ

ഓരോ സ്ക്രീൻഷോട്ടിലും, മഞ്ഞ ഫ്രെയിം എവിടെ ടാപ്പ് അല്ലെങ്കിൽ ക്ലിക്ക് ചെയ്യണമെന്ന് കാണിക്കുന്നു; നമ്പറുകൾ ക്രമം നൽകുന്നു. ആപ്പ് ഫ്രഞ്ചിലാണ്: സ്ക്രീൻഷോട്ടുകൾ അതിന്റെ ഇംഗ്ലീഷ് വിവർത്തനം കാണിക്കുന്നു.

  1. « ക്രമീകരണങ്ങൾ », « പ്രൊഫൈൽ » വിഭാഗം തുറന്ന് « മറ്റൊരു ആപ്പിൽ നിന്ന് ഇറക്കുമതി » വരെ താഴേക്ക് സ്ക്രോൾ ചെയ്യുക.

  2. « Stremio account » (1) തിരഞ്ഞെടുക്കുക. നിങ്ങളുടെ അക്കൗണ്ടിൽ സൈൻ ഇൻ ചെയ്യാതെ, « Stremio export file » (2) ഈ ഉപകരണത്തിലെ ഒരു ഫയൽ വായിക്കുന്നു.

  3. അറിയിപ്പ് വായിക്കുക, പിന്നെ « മനസ്സിലായി, തുടരുക » ടാപ്പ് ചെയ്യുക.

    നിങ്ങളുടെ Stremio ഇമെയിൽ (1), പാസ്‌വേഡ് (2) ടൈപ്പ് ചെയ്യുക, പിന്നെ « Read my library » (3).

  4. Laststream ഇറക്കുമതി ചെയ്യാവുന്നത് കാണിക്കുന്നു: « ലൈബ്രറി », « കാണാനുള്ളവ », « കണ്ടത് », « പ്ലേബാക്ക് പുരോഗതി ». വേണ്ടാത്തത് അൺടിക്ക് ചെയ്യുക (1), പിന്നെ « ഇറക്കുമതി » (2).

  5. അവസാനം, സംഗ്രഹം ഇറക്കുമതി ചെയ്ത, ഒഴിവാക്കിയ, പരാജയപ്പെട്ട ഇനങ്ങൾ കാണിക്കുന്നു. « എന്റെ ലൈബ്രറി കാണുക » ടാപ്പ് ചെയ്യുക.

  6. നിങ്ങളുടെ Stremio ശീർഷകങ്ങൾ കണ്ട നിലയും പുരോഗതിയും സഹിതം നിങ്ങളുടെ ലൈബ്രറിയിൽ ഉണ്ട്.

അറിഞ്ഞിരിക്കേണ്ടത്

  • നിങ്ങളുടെ ഇമെയിലും പാസ്‌വേഡും നിങ്ങളുടെ ഉപകരണത്തിൽ നിന്ന് നേരിട്ട് Stremio-യിലേക്ക് പോകുന്നു. Laststream-ഓ നിങ്ങളുടെ സെർവറോ അവ സ്വീകരിക്കുന്നില്ല, സൂക്ഷിക്കുന്നുമില്ല.
  • നിങ്ങളുടെ Stremio അക്കൗണ്ടിൽ ഒന്നും മാറുന്നില്ല: മുമ്പത്തെപ്പോലെ അത് ഉപയോഗിക്കുന്നത് തുടരാം.
  • പൊരുത്തമില്ലാത്ത ശീർഷകങ്ങൾ (ടിവി ചാനലുകൾ, ആഡ്-ഓൺ മാത്രമുള്ള ശീർഷകങ്ങൾ) ഒഴിവാക്കുന്നു, കാരണം റിപ്പോർട്ട് പറയുന്നു. നിങ്ങൾക്ക് അത് പകർത്താം അല്ലെങ്കിൽ ഡൗൺലോഡ് ചെയ്യാം.
  • അതേ കാർഡ് ഒരു Nuvio ബാക്കപ്പ്, ഒരു Simkl എക്സ്പോർട്ട്, അല്ലെങ്കിൽ ഒരു Plex സെർവറിന്റെ ചരിത്രം എന്നിവയും ഇറക്കുമതി ചെയ്യുന്നു. ഇറക്കുമതി തുറന്ന പ്രൊഫൈലിലേക്ക് പോകും: ഓരോ പ്രൊഫൈലിനും വീണ്ടും ചെയ്യുക.
മുമ്പത്തെ ഗൈഡ് ഒരാളെ ക്ഷണിക്കുക അടുത്ത ഗൈഡ് സുഹൃത്തുക്കളെ ചേർക്കുക
Laststream

Laststream ഉള്ളടക്കമൊന്നും ഹോസ്റ്റ് ചെയ്യുന്നില്ല: നിങ്ങൾ കോൺഫിഗർ ചെയ്യുന്ന എക്സ്റ്റൻഷനുകൾ വായിക്കുന്നു. ക്ഷണം വഴി മാത്രം.

ഗൈഡുകൾ

Laststream Stremio-യുമായി ബന്ധപ്പെട്ടതല്ല.

ഈ ഉൽപ്പന്നം TMDB API ഉപയോഗിക്കുന്നു, പക്ഷേ TMDB അംഗീകരിച്ചതോ സാക്ഷ്യപ്പെടുത്തിയതോ അല്ല.

ഒരു ഡെമോ കാറ്റലോഗ് ഉപയോഗിച്ച് എടുത്ത സ്ക്രീൻഷോട്ടുകൾ: കെട്ടിച്ചമച്ച ശീർഷകങ്ങളും AI സൃഷ്ടിച്ച പോസ്റ്ററുകളും.
