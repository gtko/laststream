ഒരു ഉറവിടം ചേർക്കുക (Stremio എക്സ്റ്റൻഷൻ)

Laststream Stremio എക്സ്റ്റൻഷനുകൾ (addons) സ്വീകരിക്കുന്നു: അവയുടെ manifest വിലാസം ഒട്ടിച്ചാൽ, ഒരു ശീർഷകം പ്ലേ ചെയ്യുമ്പോൾ അവയുടെ ലിങ്കുകൾ കാണിക്കും.

  • 3 മിനിറ്റ്
  • Windows
  • Android
  • ബ്രൗസർ

തുടങ്ങുന്നതിന് മുമ്പ്

  • ഒരു സൈൻ ഇൻ ചെയ്ത അക്കൗണ്ട്, പ്രധാന പ്രൊഫൈലിൽ.
  • എക്സ്റ്റൻഷന്റെ manifest-ന്റെ വിലാസം (സാധാരണയായി /manifest.json ൽ അവസാനിക്കുന്നു).

ഘട്ടങ്ങൾ

ഓരോ സ്ക്രീൻഷോട്ടിലും, മഞ്ഞ ഫ്രെയിം എവിടെ ടാപ്പ് അല്ലെങ്കിൽ ക്ലിക്ക് ചെയ്യണമെന്ന് കാണിക്കുന്നു; നമ്പറുകൾ ക്രമം നൽകുന്നു. ആപ്പ് ഫ്രഞ്ചിലാണ്: സ്ക്രീൻഷോട്ടുകൾ അതിന്റെ ഇംഗ്ലീഷ് വിവർത്തനം കാണിക്കുന്നു.

  1. നിങ്ങളുടെ അവതാറിൽ ടാപ്പ് ചെയ്യുക, പിന്നെ « ക്രമീകരണങ്ങൾ ».

  2. ഇടത് കോളത്തിൽ « ഉറവിടങ്ങൾ » (1) തിരഞ്ഞെടുക്കുക, പിന്നെ « ഒരു Stremio ആഡ്-ഓൺ ചേർക്കുക » (2).

  3. വിലാസം « Upstream addon URL » ൽ ഒട്ടിക്കുക. stremio:// ലിങ്കുകൾ സ്വീകരിക്കും, ഇല്ലെങ്കിൽ /manifest.json ചേർക്കും.

    സ്ക്രീൻഷോട്ടുകളിൽ വിലാസം http://localhost എന്ന് തുടങ്ങുന്നു: ഇത് ഗൈഡിനായി പ്രാദേശികമായി പ്രവർത്തിക്കുന്ന താഴെയുള്ള ഉദാഹരണ എക്സ്റ്റൻഷനാണ്. നിങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്യാൻ ആഗ്രഹിക്കുന്ന എക്സ്റ്റൻഷൻ നൽകുന്ന വിലാസം ഒട്ടിക്കുക.

  4. addon-ന്റെ പേര്, ലോഗോ, നില എന്നിവ കാണിക്കുന്ന manifest ഉടനെ വായിക്കും (1). ക്രമീകരണങ്ങളുടെ അടിയിലെ « Save » ടാപ്പ് ചെയ്യുക (2).

  5. ഒരു സിനിമ തുറന്ന് « Play » ടാപ്പ് ചെയ്യുക: ആഡ്-ഓണിന്റെ ലിങ്കുകൾ « ഉറവിടങ്ങൾ » പാനലിൽ വരും.

അറിഞ്ഞിരിക്കേണ്ടത്

  • ഒരു കാർഡിന്റെ « … » മെനു: എഡിറ്റ് ചെയ്യുക, കോൺഫിഗറേഷൻ തുറക്കുക, URL പകർത്തുക, പ്രവർത്തനക്ഷമമാക്കുക അല്ലെങ്കിൽ നിർജ്ജീവമാക്കുക, നീക്കം ചെയ്യുക.
  • ക്രമം പ്രധാനമാണ്: ഉറവിടം 1 ആദ്യം പരിശോധിക്കും. ⋮⋮ ഹാൻഡിൽ അല്ലെങ്കിൽ ↑ ↓ അമ്പടയാളങ്ങൾ ഉപയോഗിച്ച് മാറ്റുക.
  • അൺഇൻസ്റ്റാൾ ചെയ്യാൻ: നീക്കം ചെയ്യുക, പിന്നെ « Save ».
  • debrid കീ Laststream-ൽ നൽകുന്നില്ല: ഓരോ ആഡ്-ഓണും അതിന്റെ സ്വന്തം കോൺഫിഗറേഷനിൽ debrid കൈകാര്യം ചെയ്യുന്നു.

ഉദാഹരണം: ഒരു അടിസ്ഥാന എക്സ്റ്റൻഷൻ

ഒരു എക്സ്റ്റൻഷൻ രണ്ട് വിലാസങ്ങൾ നൽകുന്ന ഒരു ചെറിയ വെബ് സേവനമാണ്: /manifest.json, /stream/{type}/{id}.json.

manifest:

{
        "id": "exemple.mon-addon",
        "version": "1.0.0",
        "name": "Mon addon",
        "description": "Exemple de source pour Laststream",
        "resources": ["stream"],
        "types": ["movie", "series"],
        "idPrefixes": ["tt"],
        "catalogs": []
      }

/stream/movie/tt0000001.json എന്നതിന്റെ പ്രതികരണം:

{
        "streams": [
          {
            "name": "Mon addon",
            "title": "1080p",
            "url": "https://exemple.com/video.mp4"
          }
        ]
      }

ഈ ഗൈഡിന്റെ സ്ക്രീൻഷോട്ടുകൾക്ക് ഉപയോഗിച്ച അതേ എക്സ്റ്റൻഷനാണിത്.

മുമ്പത്തെ ഗൈഡ് ഒരു കുട്ടികളുടെ പ്രൊഫൈൽ സൃഷ്ടിക്കുക അടുത്ത ഗൈഡ് ലൈവ് ടിവി സജ്ജമാക്കുക (M3U പ്ലേലിസ്റ്റ്)
Laststream

Laststream ഉള്ളടക്കമൊന്നും ഹോസ്റ്റ് ചെയ്യുന്നില്ല: നിങ്ങൾ കോൺഫിഗർ ചെയ്യുന്ന എക്സ്റ്റൻഷനുകൾ വായിക്കുന്നു. ക്ഷണം വഴി മാത്രം.

ഗൈഡുകൾ

Laststream Stremio-യുമായി ബന്ധപ്പെട്ടതല്ല.

ഈ ഉൽപ്പന്നം TMDB API ഉപയോഗിക്കുന്നു, പക്ഷേ TMDB അംഗീകരിച്ചതോ സാക്ഷ്യപ്പെടുത്തിയതോ അല്ല.

ഒരു ഡെമോ കാറ്റലോഗ് ഉപയോഗിച്ച് എടുത്ത സ്ക്രീൻഷോട്ടുകൾ: കെട്ടിച്ചമച്ച ശീർഷകങ്ങളും AI സൃഷ്ടിച്ച പോസ്റ്ററുകളും.
