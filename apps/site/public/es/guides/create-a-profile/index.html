Crear un perfil

Cada persona de casa tiene su propio perfil: su biblioteca, progreso y ajustes les siguen en todos sus dispositivos.

  • 2 min
  • Windows
  • Android
  • Navegador

Antes de empezar

  • Una cuenta con sesión iniciada.
  • Solo el perfil principal (o alguien que conozca su código) puede añadir perfiles.

Pasos

En cada captura, el marco amarillo indica dónde pulsar o hacer clic; los números indican el orden. La app está en francés: las capturas muestran su traducción al inglés.

  1. Pulsa tu avatar arriba a la derecha (1) y luego «Cambiar de perfil» (2).

  2. En la pantalla «¿Quién está viendo?», pulsa la tarjeta «Añadir un perfil».

  3. En «Nuevo perfil», escribe su nombre (1, 20 caracteres como máximo). Si quieres, elige un avatar con «Cambiar avatar» (2) y luego un color de las 8 muestras (3).

  4. Opcional: un «Código PIN del perfil» de 4 dígitos (1), que se pedirá a partir de entonces para abrir este perfil.

    Pulsa «Crear perfil» arriba a la derecha (2).

  5. El nuevo perfil aparece junto a los demás. Pulsa «Listo» para volver a «¿Quién está viendo?» y luego pulsa el perfil para abrirlo.

Conviene saber

  • Para editar un perfil: «Gestionar perfiles» y luego pulsa el perfil. Puedes cambiar su nombre, avatar, color o código PIN.
  • Para eliminar un perfil: mismo camino, y luego la zona de peligro al final (escribe su nombre para confirmar). El perfil principal no se puede eliminar.
  • Para un niño, sigue mejor la guía Crear un perfil infantil.
