Sediakan TV langsung (senarai main M3U)

TV langsung membaca senarai main M3U daripada pembekal atau perkhidmatan IPTV anda, dan secara pilihan panduan program XMLTV.

  • 5 min
  • Windows
  • Android

Sebelum anda mula

  • Aplikasi Windows atau Android: pelayar tidak dapat mencapai kebanyakan senarai main.
  • Alamat senarai main M3U anda (dan, jika anda ada, alamat panduan XMLTV).

Langkah-langkah

Pada setiap tangkapan skrin, bingkai kuning menunjukkan tempat untuk diketik atau diklik; nombor memberikan susunannya. Aplikasi dalam bahasa Perancis: tangkapan skrin menunjukkan terjemahan Inggerisnya.

  1. Ketik avatar anda, kemudian “Tetapan”, kemudian “TV langsung” dalam lajur kiri.

  2. Dalam “Tambah senarai main M3U”, isi nama (1, pilihan), “Alamat senarai main” (2) dan, jika anda ada, “Panduan program (XMLTV)” (3, .xml atau .xml.gz).

    Ketik “Tambah senarai main” (4). Anda juga boleh “Import fail” (.m3u) daripada peranti.

  3. Setelah mesej “… saluran ditambah, panduan dikemas kini” muncul, kembali ke laman utama dan buka tab “Langsung”.

  4. Saluran anda muncul dengan lencana “Box”, bersama program-programnya. Lajur kiri menapis mengikut kategori.

  5. Ketik satu program untuk melihat butirannya, kemudian “Tonton”.

Perkara yang perlu diketahui

  • Pelanggan Freebox: “Kesan Freebox saya” menambah saluran kotak tanpa perlu menaip apa-apa.
  • Setiap senarai main boleh dinyahdayakan, dimuat semula atau dialih keluar daripada barisnya, di bawah “Senarai main M3U”.
  • Senarai main akaun diuruskan oleh profil utama.

Format yang dijangka

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

Baris pertama mesti #EXTM3U. Setiap #EXTINF diikuti alamat strim (http, https, rtsp, rtp atau udp). group-title memberikan kategori, tvg-chno nombor (1 hingga 9999), tvg-id dipautkan ke panduan XMLTV.

Jika ia tidak berfungsi

  • “Alamat ini tidak memulangkan senarai main M3U.” → alamat itu menunjuk ke halaman web atau fail dalam format lain.
  • “Tiada saluran ditemui dalam senarai main ini.” → fail kosong atau rosak.
  • “Alamat tidak dapat dicapai” → semak alamat dan sambungan anda (dan rangkaian kotak anda untuk Freebox).
  • Dalam pelayar → pelayar web tidak dapat mencapai kebanyakan senarai main: gunakan aplikasi Windows atau Android.
