    64 位安装程序 · Windows 10 和 11

    完整的原生播放器（mpv）、迷你播放器和自动更新。

    下载 Windows 版

    如果出现 Windows SmartScreen：点按“更多信息”，然后选择“仍要运行”。有旧版应用？安装此版本即可：登录信息和设置会保留，之后卸载旧版即可。

  • Android

    APK 文件 · 手机、平板和 Android 电视

    原生 libVLC 播放器、迷你播放器和一键更新。

    下载 APK
    安装方法
    1. 将 APK 文件下载到你的手机或平板。
    2. 打开它。Android 会询问是否允许从此来源安装：请为你的浏览器选择“允许来自未知来源”（或“允许来自此来源”）。
    3. 确认安装，然后打开 Laststream。

  • Mac

    磁盘映像 · macOS 11 或更高版本

    完整的原生播放器（mpv）、迷你播放器和自动更新。

    Apple Silicon 芯片的 Mac（M1 及更新型号） Intel 芯片的 Mac
    安装方法
    1. 打开 .dmg 文件，然后将 Laststream 拖到“应用程序”中。
    2. 该应用尚未经过 Apple 公证：如果 macOS 拒绝打开，请前往“系统设置”，“隐私与安全性”，然后选择“仍要打开”。
    3. 查看你的 Mac：点按苹果菜单，选择“关于本机”。“芯片 Apple”表示 Apple Silicon，“处理器 Intel”表示 Intel。

    完整的原生播放器（mpv）和迷你播放器。AppImage 会自动更新。

    • AppImage：先将文件设为可执行（属性，或 chmod +x），然后运行它。
    • .deb（Debian、Ubuntu）： sudo apt install ./Laststream-*.deb。之后的更新会随新的 .deb 包提供。

常见问题

常见问题。

需要详细步骤？阅读指南 →

如何获得账户？

注册需要邀请。请向告诉你 Laststream 的人索取推荐邀请券：每个账户有 2 张。

Laststream 多少钱？

在线服务每年 €24（每月 €2），作为支持者订阅，覆盖全家。喜欢的话？选择“支持，我很喜欢”，即可自定义每年金额，从 €24 起，无上限。受好友邀请的话，首年为 €12。你也可以在自己的服务器上免费运行 Laststream：其代码在 GitHub 上公开。

订阅包含插件或内容吗？

不。Laststream 不提供也不安装任何 Stremio 插件，也不托管任何内容。订阅费用用于服务：账户、同步、应用和服务器。你需要自行添加所用的资源。

Laststream 提供电影和剧集吗？

不。Laststream 不托管任何内容：它是一个播放器和目录，读取你自行配置的插件。你需对所添加的内容负责，并遵守所在国家或地区的版权法律。

我的数据会跟随我在不同设备间切换吗？

是：播放进度、片单和设置会与你的账户同步。

有 iPhone 或 iPad 应用吗？

原生应用正在规划中。在此期间，网页版可像应用一样安装，使用效果很好。

资源如何选择？

来自你的插件的资源按语言、画质、大小排序。Laststream 会自动开始最适合你当前网速的最佳资源，你也随时可以从列表中选择其他资源。

我的 Stremio 插件能用吗？

是。Laststream 可读取 Stremio 格式的插件：粘贴插件 manifest 的网址，其目录和资源即会添加到应用中。

观看还需要其他服务吗？

这取决于你配置的插件。Laststream 不提供任何此类服务：由你自行选择资源，如果资源需要，也由你自行提供相应账户。

儿童资料如何运作？

你可以在自己的资料旁创建儿童资料。它只显示适合其年龄的内容（依据可用的年龄分级），不能打开插件或设置，并且只能通过密码退出。

好友和一起看可以使用吗？

是。好友、消息、动态、共享媒体库和一起看在有账户时均可使用，但不能在儿童资料中使用。你的媒体库默认私密，每位参与者都使用各自的资源观看：账户之间不共享任何内容。

加入一起看需要账户吗？

不需要。访客可以通过你发送的邀请链接加入一起看，无需账户。他们使用自己的资源观看。

应用如何更新？

在 Windows、Mac 和 Linux（AppImage）上，更新是自动的。在 Android 上，应用会提供新版本，一键即可安装。网页版始终是最新版本。
