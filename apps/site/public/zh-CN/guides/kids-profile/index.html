创建儿童资料

儿童资料只显示分级已知且不高于所选年龄的作品。退出需要家长密码。

  • 3 分钟
  • Windows
  • Android
  • 浏览器

步骤

每张截图中，黄色框标示了应点按或点击的位置，数字表示顺序。应用原本使用法语，截图展示的是其英文译本。

  1. 按照创建资料指南的步骤打开“新建资料”（头像、“切换资料”、“添加资料”），然后输入其名字。

  2. 在“家长控制”下，开启“儿童资料”。

  3. 选择“最高年龄”（1）：10、12、16 或 18（默认 12）。勾选“允许的分区”（2），参见下表。

  4. 如果主资料尚未设置家长密码，请输入一个 4 位数字（1）。它用于保护退出儿童资料的操作。

    点按“创建资料”（2）。

  5. 点按“完成”，然后进入儿童资料：其首页只显示适合其年龄的作品。

允许的分区

分区默认勾选
卡通是
家庭电影是
儿童剧集是
迪士尼和皮克斯经典是
适合儿童的动画是
儿童新片是
平台（Disney+、Netflix）是
儿童电视否

未开启“儿童电视”时，孩子看不到“电视”标签。

退出儿童资料

点按其头像，然后选择“切换资料”：需要输入家长密码。

须知

  • 没有年龄分级的作品会被隐藏。
  • 孩子看不到“设置”、“统计”、好友或媒体库共享。
