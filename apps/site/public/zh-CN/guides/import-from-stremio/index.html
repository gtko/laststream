导入你的 Stremio 媒体库

将你的 Stremio 媒体库、已看作品和进度导入你的 Laststream 资料。导入只读取你的账户，绝不会修改它。

  • 3 分钟
  • Windows
  • Android
  • 浏览器

开始之前

  • 你的 Stremio 邮箱和密码，或一个 Stremio 导出文件。
  • 接收这些作品的 Laststream 资料已打开。

步骤

每张截图中，黄色框标示了应点按或点击的位置，数字表示顺序。应用原本使用法语，截图展示的是其英文译本。

  1. 打开“设置”，选择“资料”类别，向下滚动到“从其他应用导入”。

  2. 选择“Stremio 账户”（1）。无需登录你的账户，选择“Stremio 导出文件”（2）即可读取本设备上的文件。

  3. 阅读提示，然后点按“知道了，继续”。

    输入你的 Stremio 邮箱（1）和密码（2），然后点击“读取我的媒体库”（3）。

  4. Laststream 会显示可导入的内容：“媒体库”、“待看列表”、“已看”、“播放进度”。取消勾选不需要的项目（1），然后点击“导入”（2）。

  5. 最后，摘要会显示已导入、已跳过和失败的条目。点按“查看我的媒体库”。

  6. 你的 Stremio 作品已进入媒体库，并保留其观看状态和进度。

须知

  • 你的邮箱和密码直接从你的设备发送至 Stremio。Laststream 和你的服务器都不会接收，也不会保存。
  • 你的 Stremio 账户不会发生任何变化：你可以继续照常使用。
  • 无法匹配的作品（电视频道、仅插件提供的作品）会被跳过，报告中会说明原因。你可以复制或下载该报告。
  • 同一张卡片还可导入 Nuvio 备份、Simkl 导出文件或 Plex 服务器的观看记录。导入内容会进入当前打开的资料：每个资料都需分别导入一次。
