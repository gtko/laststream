Gumawa ng profile

May sariling profile ang bawat tao sa bahay: sumusunod sa kanila ang library, progreso, at mga setting sa lahat ng device nila.

  • 2 min
  • Windows
  • Android
  • Browser

Bago ka magsimula

  • Naka-sign in na account.
  • Ang pangunahing profile lang (o ang nakakaalam ng code nito) ang puwedeng magdagdag ng profile.

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. I-tap ang avatar mo sa kanang itaas (1), saka ang “Lumipat ng profile” (2).

  2. Sa screen na “Sino ang nanonood?”, i-tap ang “Magdagdag ng profile” tile.

  3. Sa “Bagong profile”, i-type ang pangalan nila (1, hanggang 20 karakter). Kung gusto, pumili ng avatar gamit ang “Palitan ang avatar” (2), saka ng kulay mula sa 8 swatch (3).

  4. Opsyonal: 4 na digit na “Profile PIN code” (1), na hihingin mula noon para mabuksan ang profile na ito.

    I-tap ang “Gumawa ng profile” sa kanang itaas (2).

  5. Lalabas ang bagong profile sa tabi ng iba. I-tap ang “Tapos na” para bumalik sa “Sino ang nanonood?”, saka i-tap ang profile para buksan ito.

Magandang malaman

  • Para i-edit ang profile: “Manage profiles”, saka i-tap ang profile. Maaari mong baguhin ang pangalan, avatar, kulay, o PIN code nito.
  • Para mag-delete ng profile: parehong daan, saka ang danger zone sa ilalim (i-type ang pangalan nito para kumpirmahin). Hindi maaaring i-delete ang pangunahing profile.
  • Para sa bata, sundin na lang ang gabay na Gumawa ng profile ng bata.
