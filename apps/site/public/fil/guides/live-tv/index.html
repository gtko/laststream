I-set up ang live TV (M3U playlist)

Binabasa ng live TV ang mga M3U playlist mula sa iyong provider o IPTV service, at opsyonal na XMLTV na gabay sa programa.

  • 5 min
  • Windows
  • Android

Bago ka magsimula

  • Ang Windows o Android app: hindi maabot ng browser ang karamihan ng playlist.
  • Ang address ng M3U playlist mo (at, kung mayroon ka, ang address ng XMLTV guide).

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. I-tap ang avatar mo, saka ang “Mga setting”, saka ang “Live TV” sa kaliwang hanay.

  2. Sa “Magdagdag ng M3U playlist”, punan ang pangalan (1, opsyonal), ang “Address ng playlist” (2), at kung mayroon ka, ang “Gabay sa programa (XMLTV)” (3, .xml o .xml.gz).

    I-tap ang “Idagdag ang playlist” (4). Puwede ka ring “Mag-import ng file” (.m3u) mula sa device.

  3. Kapag lumabas ang mensaheng “… na channel ang naidagdag, na-update ang gabay”, bumalik sa home at buksan ang “Live” tab.

  4. Lalabas ang mga channel mo na may “Box” badge, kasama ang mga programa nila. Sinasala ng kaliwang hanay ang mga kategorya.

  5. I-tap ang isang programa para makita ang mga detalye nito, saka ang “Panoorin”.

Magandang malaman

  • Subscriber ng Freebox: idinaragdag ng “Detect my Freebox” ang mga channel ng box nang walang kailangang i-type.
  • Maaaring i-disable, i-refresh, o alisin ang bawat playlist mula sa hanay nito, sa ilalim ng “M3U playlists”.
  • Pinamamahalaan ng pangunahing profile ang mga playlist ng account.

Inaasahang format

#EXTM3U
      #EXTINF:-1 tvg-id="channel1.fr" tvg-name="Channel 1" tvg-logo="https://example.com/logo1.png" group-title="General" tvg-chno="1",Channel 1
      https://example.com/live/channel1.m3u8

Dapat #EXTM3U ang unang linya. Sinusundan ng stream address (http, https, rtsp, rtp, o udp) ang bawat #EXTINF. Ibinibigay ng group-title ang kategorya, ng tvg-chno ang numero (1 hanggang 9999), at nag-uugnay ang tvg-id sa XMLTV guide.

Kung hindi ito gumana

  • “Ang address na ito ay hindi nagbabalik ng M3U playlist.” → nakaturo ang address sa web page o file na ibang format.
  • “Walang nakitang channel sa playlist na ito.” → walang laman o sira ang file.
  • “Hindi maabot ang address” → suriin ang address at ang iyong koneksyon (at ang network ng box mo para sa Freebox).
  • Sa browser → hindi maabot ng web browser ang karamihan ng playlist: gamitin ang Windows o Android app.

Ipinapakita ng app ang mga mensaheng ito sa Pranses.
