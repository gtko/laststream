I-import ang iyong Stremio library

Dalhin ang iyong Stremio library, mga napanood na titulo, at progreso sa iyong Laststream profile. Binabasa lang ng import ang account mo at hindi ito kailanman binabago.

  • 3 min
  • Windows
  • Android
  • Browser

Bago ka magsimula

  • Ang Stremio email at password mo, o isang Stremio export file.
  • Bukas ang Laststream profile na dapat tumanggap ng mga titulo.

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. Buksan ang “Mga setting”, kategoryang “Profile”, at mag-scroll pababa sa “Mag-import mula sa ibang app”.

  2. Piliin ang “Stremio account” (1). Nang hindi nag-si-sign in sa account mo, binabasa ng “Stremio export file” (2) ang isang file sa device na ito.

  3. Basahin ang paunawa, saka i-tap ang “Sige, magpatuloy”.

    I-type ang Stremio email (1) at password (2), saka “Basahin ang library ko” (3).

  4. Ipinapakita ng Laststream kung ano ang puwedeng i-import: “Library”, “Watchlist”, “Watched”, “Playback progress”. Alisin ang tsek sa ayaw mo (1), saka “Import” (2).

  5. Sa dulo, ipinapakita ng buod ang mga na-import, nilaktawan, at pumalya. I-tap ang “Tingnan ang library ko”.

  6. Nasa library mo ang mga titulo mo sa Stremio, kasama ang napanood na status at progreso.

Magandang malaman

  • Diretsong napupunta mula sa device mo papunta sa Stremio ang email at password mo. Hindi ito natatanggap ng Laststream o ng server mo, at hindi ito itinatabi.
  • Walang magbabago sa iyong Stremio account: maaari mo pa rin itong gamitin gaya ng dati.
  • Nilalaktawan ang mga titulong walang katugma (TV channel, mga titulong addon lang), at sasabihin ng ulat kung bakit. Maaari mo itong kopyahin o i-download.
  • Ang parehong card ay nag-i-import din ng Nuvio backup, Simkl export, o history ng Plex server. Mapupunta ang import sa bukas na profile: ulitin ito para sa bawat profile.

Mga gabay

Hindi kaanib ng Stremio ang Laststream.

Gumagamit ang produktong ito ng TMDB API, ngunit hindi ito inendorso o sertipikado ng TMDB.

Ginawa ang mga screenshot gamit ang demo na katalogo: mga kathang-isip na titulo at mga poster na gawa ng AI.
