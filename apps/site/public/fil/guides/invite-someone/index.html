Mag-imbita ng iba

Sa imbitasyon lang ang pag-sign up. Magbigay ng isa sa iyong imbitasyon: isang personal na link, kasama ang tala mo at tatlong titulong matutuklasan nila.

  • 2 min
  • Windows
  • Android
  • Browser

Bago ka magsimula

  • Naka-sign in na account, sa profile ng matanda.
  • Ilang titulo sa iyong library kung gusto mong magmungkahi ng paborito.

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. Buksan ang “Mga setting” (ang avatar mo sa kanang itaas), kategoryang “Profile”. I-tap ang “Mga imbitasyon ko” para ilabas ang mga imbitasyon mo.

  2. Pumili ng available na imbitasyon: “Ibigay ang imbitasyong ito”.

  3. Isulat ang tala mo (1, hanggang 280 karakter): lumalabas ito sa welcome page nila. Pumili ng hanggang 3 paborito mula sa library mo (2).

    I-tap ang “Kopyahin ang link” (3), o ang “Ibahagi…” para ipadala ito diretso mula sa telepono mo.

  4. Ipadala ang link sa anumang paraang gusto mo (mensahe, email…). Ipinapakita ng imbitasyon ang “Naipadala, nakabinbin” hanggang gawin nila ang account nila.

Magandang malaman

  • Isang beses lang gumagana ang bawat imbitasyon. Valid ang link sa loob ng 14 na araw pagkatapos ipadala; kung walang gumamit nito, babalik sa iyo ang imbitasyon.
  • Ibinabalik agad ng “Kanselahin ang imbitasyon” kung napili mo ang maling tao.
  • Ang taong iniimbitahan mo ay puwedeng maging kaibigan mo sa isang click. Mas mabilis, nang walang tala: ang Friends panel, “Mag-imbita ng iba”, “Kopyahin ang link”.
  • Para bigyan ng access ang isa sa mga profile mo (parehong sambahayan), gamitin ang “Household invitations” card sa ibaba lang.
