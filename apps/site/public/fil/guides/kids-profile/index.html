Gumawa ng profile ng bata

Nagpapakita lang ang profile ng bata ng mga titulong may kilalang age rating at hindi lalampas sa piniling edad. Kailangan ang parental code para makalabas dito.

  • 3 min
  • Windows
  • Android
  • Browser

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. Buksan ang “Bagong profile” gaya sa gabay na Gumawa ng profile (avatar, “Lumipat ng profile”, “Magdagdag ng profile”), saka i-type ang pangalan nila.

  2. Sa ilalim ng “Parental controls”, i-on ang “Profile ng bata”.

  3. Pumili ng “Pinakamataas na edad” (1): 10, 12, 16, o 18 (12 bilang default). Lagyan ng tsek ang “Mga pinapayagang seksyon” (2), tingnan ang talahanayan sa ibaba.

  4. Kung wala pang parental code ang pangunahing profile, mag-type ng 4 na digit (1). Pinoprotektahan nito ang paglabas sa profile ng bata.

    I-tap ang “Gumawa ng profile” (2).

  5. I-tap ang “Tapos na”, saka ang profile ng bata: ang home nito ay nagpapakita lang ng mga titulong angkop sa edad nito.

Paglabas sa profile ng bata

I-tap ang avatar nito, saka ang “Lumipat ng profile”: hihingin ang parental code.

Magandang malaman

  • Nakatago ang titulong walang age rating.
  • Hindi nakikita ng bata ang Mga setting, Statistics, mga kaibigan, o pagbabahagi ng library.
