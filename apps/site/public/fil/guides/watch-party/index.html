Magsimula ng sabayang panonood

Manood ng parehong pelikula sa parehong oras, bawat isa sa bahay. Gamit ng bawat isa ang sarili nilang pinagmulan: pinananatiling naka-sync ng sabayang panonood ang playback mo, at walang video stream na ibinabahagi.

  • 3 min
  • Windows
  • Android
  • Browser

Bago ka magsimula

  • Naka-sign in na account, sa profile ng matanda.
  • Kahit isang kaibigan (tingnan ang Magdagdag ng kaibigan), o ang room link na ibabahagi.
  • Pinagmulang humahanap ng titulo (tingnan ang Magdagdag ng Stremio source).

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. Buksan ang pahina ng pelikula at i-tap ang “…” button sa tabi ng Play.

  2. Piliin ang “Manood kasama ang…”.

  3. Nakalista ang mga online mong kaibigan, may “Mag-imbita”. Para pagsamahin ang ilang tao, i-tap ang “Magbukas ng kuwarto para sa titulong ito”.

  4. Panatilihin ang “Pribado” (1) para sa mga panauhin mo lang, o pumili ng “Publiko” para ilista ang kuwarto sa ilalim ng “Mga sabayang panonood”.

    Lagyan ng tsek ang mga kaibigang iimbitahan (2), saka ang “Buksan ang waiting room” (3).

  5. Sa waiting room, nakikita ng lahat na inihahanda ang kanilang pinagmulan. Ibahagi ang link (1) sa taong walang account, o mag-imbita pa ng kaibigan (2).

    Kapag handa na ang lahat, simulan ang playback (3): nananatiling naka-sync ang playback.

Magandang malaman

  • Mga setting ng kuwarto: “Sino ang kumokontrol sa playback” (lahat o ang host), “Maghintay sa mga nahuli”, at “Mga reaksyon sa screen”.
  • Pinapapasok din ng room link ang mga taong walang account: 4 na upuan, valid sa loob ng 12 oras. Hanggang 20 tao ang kayang tanggapin ng isang kuwarto.
  • Tinitipon ng pahinang “Together” ang mga bukas na kuwarto, “Sumali gamit ang code”, at “Magplano ng gabi” para sa susunod.
  • Bawat isa ay nanonood gamit ang sarili nilang pinagmulan at wika: kung wala sa wika ng kuwarto ang pinagmulan mo, sasabihin ito ng kuwarto sa iyo.
