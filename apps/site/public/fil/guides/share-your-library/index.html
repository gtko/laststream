Ibahagi ang iyong library

Pribado bilang default ang library mo. Hayaang makita ng mga kaibigan mo ang mga titulong pipiliin mo, o ang buong library mo nang sabay.

  • 1 min
  • Windows
  • Android
  • Browser

Bago ka magsimula

  • Naka-sign in na account, sa profile ng matanda (walang ibinabahagi ang profile ng bata).
  • Mga titulo sa iyong library, at mga kaibigan para makita ang mga ito.

Mga hakbang

Sa bawat screenshot, ipinapakita ng dilaw na frame kung saan i-tap o i-click; ibinibigay ng mga numero ang pagkakasunod-sunod. Nasa Pranses ang app: ipinapakita ng mga screenshot ang English na salin nito.

  1. Buksan ang menu na “Explore” (1), saka ang “My list” (2). Sa telepono, ito ang “My list” tab sa ibaba ng screen.

  2. May mata sa kanang itaas ang bawat poster. Kapag may guhit, pribado ang titulo.

  3. I-tap ang mata: magbubukas ito at makikita ng mga kaibigan mo ang titulo. I-tap muli para gawin itong pribado.

  4. Para baguhin ang lahat nang sabay: “Ibahagi sa mga kaibigan ko” (1) o “Panatilihing pribado ang lahat” (2). Sa filter na “Mga pelikula” o “Serye”, tanging ang mga titulong iyon ang magbabago.

  5. Hihingin ng Laststream ang kumpirmasyon mo, saka sasabihin kung ilang titulo ang makikita ng mga kaibigan mo.

Magandang malaman

  • Nakikita ng mga kaibigan mo ang mga ibinahagi mong titulo sa Friends panel nila: i-tap nila ang pangalan mo, saka “Tingnan ang buong library nila”. Puwede nilang idagdag ang mga ito sa sarili nilang library.
  • Nananatiling pribado ang titulong idadagdag mo mamaya hanggang buksan mo ang mata nito.
